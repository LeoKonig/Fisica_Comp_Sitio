⚙ Ruta ATS2

Elegiste el lenguaje ATS2: un camino a la física computacional con un lenguaje que combina tipos dependientes, tipos lineales y rendimiento cercano a C.

En ATS separas lo que se calcula de lo que se razona: los índices estáticos del tipo (como la longitud de un arreglo) los comprueba el compilador antes de ejecutar, y el programa se compila a código nativo sin costo en tiempo de ejecución. Perfecto para simulaciones donde importan tanto la corrección como la velocidad.

Usaremos double para calcular e int indexado por valores estáticos para garantizar propiedades como dimensiones y cotas.

// Una definición cuyo tipo es su propio teorema
fun doble {n:int} (x: int(n)): int(2*n) = x + x

implement main0 () = println! (doble 21)

Entorno con Nix. Desde la carpeta Nix del repositorio entra al shell dedicado (necesitas Nix con flakes activados):

cd Nix
nix develop .#ats2

patscc -DATS_MEMALLOC_LIBC -o doble doble.dats
./doble

El shell incluye gmp y blas para las unidades con aritmética de precisión arbitraria y álgebra lineal. Si el tipo declarado no se cumple, patscc rechaza el programa antes de generar el ejecutable. La Introducción de ATS2 (Unidad 0) cubre la sintaxis que necesitas para iniciar el curso.
