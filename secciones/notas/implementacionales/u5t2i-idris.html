Condiciones de Frontera y Soluciones Empalmadas: Shooting Method · Implementación (Idris2)

Nota Implementacional
🜂 Implementación en: Idris2
← Nota conceptual · Práctica →

Cómo leer esta nota. Cada pestaña corresponde a una pestaña de la nota conceptual y sigue el esquema Idea → Predice → Ejecuta → Lee → Tu turno. Todas las salidas se obtuvieron con Idris2 0.7.0.

Las definiciones (bloques sin prompt) van en un archivo U5T2.idr. Las consultas (con el prompt U5T2>) se escriben en el REPL, sin el prompt. Abre el REPL con idris2 U5T2.idr y usa :r para recargar el archivo cuando añadas algo. Esta nota no necesita Exacto.idr.

El método de disparo como composición. La nota conceptual describe el método como \(E \mapsto (\psi_L, \psi_R) \mapsto F(E) \mapsto E_n\). En Idris es literalmente eso: una función de \(E\) que integra, otra que empalma, y la bisección de /u2/t6, que recibe la función de empalme como argumento. Empezamos con el integrador de /u5/t1 y la bisección.

Archivo U5T2.idr:

module U5T2

import Data.List
import Data.Stream
import Data.Maybe

%default total

-- Numerov como despliegue (copiado de /u5/t1)
record Estado where
  constructor MkEstado
  anterior : Double
  actual   : Double
  posicion : Double

pasoNumerov : (Double -> Double) -> Double -> Estado -> Estado
pasoNumerov f h (MkEstado pm p x) =
  let w : Double -> Double
      w y = 1 - h * h / 12 * f y
  in MkEstado p ((2 * p * (1 + 5 * h * h / 12 * f x) - pm * w (x - h)) / w (x + h)) (x + h)

numerov : (Double -> Double) -> Double -> Double -> (Double, Double) -> Stream Double
numerov f h x0 (p0, p1) = p0 :: map actual (iterate (pasoNumerov f h) (MkEstado p0 p1 (x0 + h)))

pasos : Double -> Double -> Nat
pasos d h = cast (the Integer (cast (floor (d / h + 0.5))))

-- bisección (ver /u2/t6): 60 mitades del intervalo [a, b], donde g cambia de signo
biseccion : (Double -> Double) -> Double -> Double -> Double
biseccion g a b = ir 60 a b
  where
    ir : Nat -> Double -> Double -> Double
    ir Z     x y = (x + y) / 2
    ir (S k) x y = let m = (x + y) / 2
                   in if (g m < 0) == (g x < 0) then ir k m y      -- el cambio de signo está en [m, y]
                                                else ir k x m
  • La función de empalme como funcional de la energía
  • El problema del overflow: derivada logarítmica como función regular

Idea. Primero el pozo infinito, con la función de fallo analítica y después con Numerov, contando nodos. Luego el oscilador armónico: integramos desde los dos extremos, empalmamos con el wronskiano en \(x_m = 0.5\), y la bisección encuentra los niveles. Comparamos con el disparo de un extremo al otro.

Recuerda: el wronskiano \(W = \psi_L\psi'_R - \psi_R\psi'_L\) se anula exactamente cuando las dos mitades son proporcionales, y no depende de cómo se normalizó cada una.

El pozo infinito

Añade a U5T2.idr:

-- la función de fallo analítica del pozo [0, 1]: ψ(1; E) = sin k / k, con k = √(2E)
gPozo : Double -> Double
gPozo e = let k = sqrt (2 * e) in sin k / k

-- el disparo con Numerov: ψ'' = −2E ψ desde ψ(0) = 0, en 100 pasos de 0.01 hasta x = 1
dispararPozo : Double -> List Double
dispararPozo e = take 101 (numerov (const (-2 * e)) 0.01 0 (0, 0.01))

-- el valor en la otra pared
fallo : Double -> Double
fallo e = fromMaybe 0 (last' (dispararPozo e))

-- nodos: cambios de signo entre puntos interiores (sin las dos paredes)
nodos : List Double -> Nat
nodos ps = let interior = take (length ps `minus` 2) (drop 1 ps)
           in length (filter id (zipWith (\a, b => a * b < 0) interior (drop 1 interior)))

La función de fallo numérica es fallo: la composición de “disparar” y “tomar el valor en la otra pared” (last' devuelve un Maybe, por si la lista estuviera vacía). La bisección la recibe igual que a gPozo.

Predice. ¿Reproduce gPozo la tabla de bisección de la nota conceptual? ¿Cuántos nodos tendrá la solución disparada con \(E = 3, 10, 30, 60\), si los niveles son \(\frac{k^2\pi^2}{2} = 4.93,\ 19.74,\ 44.41,\ 78.96\)?

Ejecuta.

U5T2> [ (e, gPozo e) | e <- [4.5, 5, 4.75, 4.875, 4.9375] ]
[(4.5, 0.0470400026866224), (5.0, -0.0065407069689387), (4.75, 0.019255926929416176), (4.875, 0.006114491713813577), (4.9375, -2.7323217589931664e-4)]
U5T2> (biseccion gPozo 4.5 5, pi * pi / 2, biseccion gPozo 19.5 20, 2 * pi * pi)
(4.934802200544679, (4.934802200544679, (19.739208802178716, 19.739208802178716)))
U5T2> :exec printLn [ (e, nodos (dispararPozo e)) | e <- [3, 10, 30, 60] ]
[(3.0, 0), (10.0, 1), (30.0, 2), (60.0, 3)]
U5T2> :exec printLn (biseccion fallo 3 10, biseccion fallo 10 30)
(4.934802180514231, 19.73920752012637)

Lee.

  • Los valores de \(g\) son los de la tabla de la nota conceptual, y la bisección da \(E_1 = \frac{\pi^2}{2}\) y \(E_2 = 2\pi^2\) en todas las cifras.
  • La solución disparada tiene \(0, 1, 2, 3\) nodos: tantos como niveles hay por debajo de \(E\). Sabiendo eso, el intervalo \([3, 10]\) contiene solo a \(E_1\), y \([10, 30]\) solo a \(E_2\).
  • Con Numerov, los niveles salen \(4.9348022\) y \(19.739208\): errores de \(2\times10^{-8}\) y \(10^{-6}\), el error de Numerov con \(h = 0.01\), mayor para el nivel que oscila más.

El oscilador armónico, con empalme

Añade a U5T2.idr:

-- el oscilador: f(x) = x² − 2E
fOsc : Double -> Double -> Double
fOsc e x = x * x - 2 * e

-- integra desde x0 (con ψ = 0 y luego 10⁻¹⁰) hasta xm; devuelve (ψ(xm), ψ'(xm))
mitad : (Double -> Double) -> Double -> Double -> Double -> (Double, Double)
mitad f h x0 xm =
  let n  = pasos (xm - x0) h
      ps = numerov f h x0 (0, 1.0e-10)
  in (index n ps, (index (S n) ps - index (n `minus` 1) ps) / (2 * h))

-- el wronskiano en xm de las mitades desde −l y desde +l, con cada mitad dividida entre √(ψ² + ψ'²)
empalme : (Double -> Double) -> Double -> Double -> Double -> Double
empalme f h l xm =
  let (pL, dL) = mitad f h (-l) xm
      (pR, dR) = mitad f (-h) l xm                -- paso negativo: de derecha a izquierda
      tam : Double -> Double -> Double
      tam p d = sqrt (p * p + d * d)
  in (pL * dR - pR * dL) / (tam pL dL * tam pR dR)

-- el nivel n por bisección de la función de empalme, en [n + 0.2, n + 0.8]
nivel : Double -> Nat -> Double
nivel h n = biseccion (\e => empalme (fOsc e) h 6 0.5) (cast n + 0.2) (cast n + 0.8)

fOsc e es la función \(x \mapsto x^2 - 2E\): aplicar fOsc a un solo argumento fija \(E\) y devuelve la \(f\) que Numerov necesita. mitad sirve para las dos mitades: la derecha es la misma integración con paso \(-h\), y pasos (xm - x0) h da un número positivo de pasos en los dos casos. La derivada en \(x_m\) es la diferencia centrada de /u2/t2; con paso negativo, el elemento S n está a la izquierda, y la división entre 2 * h corrige el signo sola.

Predice. ¿Cruza \(F(E)\) el cero limpiamente en \(E = 0.5\)? ¿Cuánto mejoran los niveles al dividir \(h\) entre 2?

Ejecuta.

U5T2> :exec printLn [ (e, empalme (fOsc e) 0.05 6 0.5) | e <- [0.3, 0.4, 0.5, 0.6, 0.7] ]
[(0.3, -0.6067478854543737), (0.4, -0.34167614910307514), (0.5, 8.894526378569022e-8), (0.6, 0.3611942736624487), (0.7, 0.6686432676325021)]
U5T2> :exec printLn [ [ abs (nivel h n - (cast n + 0.5)) | n <- [0, 1, 2, 5] ] | h <- [0.1, 0.05, 0.025] ]
[[3.911681867307948e-7, 2.739270926532811e-6, 9.787961667839795e-6, 9.059160266389199e-5], [2.442253399514982e-8, 1.709746570988102e-7, 6.106958023721631e-7, 5.629700691400785e-6], [1.526003767793327e-9, 1.0682252860050312e-8, 3.814876059493599e-8, 3.368331000785929e-7]]

Lee.

  • \(F(E)\) vale \(-0.607,\ -0.342,\ 9\times10^{-8},\ +0.361,\ +0.669\): la tabla de la nota conceptual. Es suave, y cambia de signo una sola vez en el intervalo.
  • Los errores de los niveles \(n = 0, 1, 2, 5\) son los de la nota conceptual. Cada fila es 16 veces mejor que la anterior: el orden 4 de Numerov llega intacto a la energía. En cada fila, el error crece con \(n\).

Disparar de un extremo al otro

Añade a U5T2.idr:

-- una sola pasada de −6 a +6 con h = 0.05: (ψ(0), ψ(6))
disparoUnico : Double -> (Double, Double)
disparoUnico e = let ps = numerov (fOsc e) 0.05 (-6) (0, 1.0e-10) in (index 120 ps, index 240 ps)

Predice. Si \(\psi(6)\) fuera la función de fallo, ¿qué tan sensible sería a \(E\)? Con el \(E\) exacto, ¿será \(\psi(6)\) del tamaño del arranque, \(10^{-10}\)?

Ejecuta.

U5T2> :exec printLn [ (e, disparoUnico e) | e <- [0.49, 0.4999, 0.5, 0.5001, 0.51] ]
[(0.49, (0.011248204857995298, 2259.7144009204385)), (0.4999, (0.01094667272707034, 21.54295269447673)), (0.5, (0.01094366192474612, -0.005260093156648777)), (0.5001, (0.010940651817196714, -21.53275594113297)), (0.51, (0.010646066952979635, -2052.4906849797208))]

Lee. Es la tabla de la nota conceptual. \(\psi(0)\) casi no cambia, pero \(\psi(6)\) pasa de \(+21.5\) a \(-21.5\) con un cambio de \(2\times10^{-4}\) en \(E\), y con \(E = 0.5\) exacto vale \(-0.0053\), cincuenta millones de veces el arranque. La segunda mitad del recorrido integra hacia una región prohibida en el sentido inestable.

Tu turno. Cambia el punto de empalme a \(x_m = 3\), dentro de la región prohibida derecha, y repite la tabla de errores de los niveles. ¿Se degrada la precisión? ¿Y con \(x_m = -0.5\)?

Idea. Con la frontera en \(L = 40\), Numerov desborda. Integramos en cambio la ecuación de Riccati de la derivada logarítmica, \(\mathcal L' = f - \mathcal L^2\), con RK4, y comprobamos que olvida su condición inicial y que da \(E_0\) sin desbordar.

Recuerda: \(\mathcal L = \psi'/\psi\) no depende de la escala de \(\psi\); en una región prohibida tiene un punto fijo atractor \(\mathcal L = +\kappa\), que corresponde a \(e^{\kappa x}\).

Añade a U5T2.idr:

-- cuántos valores del Stream son finitos antes del primer infinito o NaN (mirando a lo más `maximo`)
primerInfinito : Nat -> Stream Double -> Nat
primerInfinito Z         _         = 0
primerInfinito (S resto) (p :: ps) =
  if p /= p || p == 1 / 0 || p == -1 / 0 then 0 else S (primerInfinito resto ps)

-- RK4 (ver /u3/t3) para una EDO escalar y' = g(x, y): el Stream de pares (x, y)
rk4Escalar : (Double -> Double -> Double) -> Double -> (Double, Double) -> Stream (Double, Double)
rk4Escalar g h = iterate paso
  where
    paso : (Double, Double) -> (Double, Double)
    paso (x, y) =
      let k1 = g x y
          k2 = g (x + h / 2) (y + h / 2 * k1)
          k3 = g (x + h / 2) (y + h / 2 * k2)
          k4 = g (x + h) (y + h * k3)
      in (x + h, y + h / 6 * (k1 + 2 * k2 + 2 * k3 + k4))

-- la ecuación de Riccati del oscilador: L' = f − L²
riccati : Double -> Double -> Double -> Double
riccati e x l = fOsc e x - l * l

-- L_L(0), integrando desde x = −40 con L = 40 y h = 0.01 (4000 pasos)
logDerivadaEn0 : Double -> Double
logDerivadaEn0 e = snd (index 4000 (rk4Escalar (riccati e) 0.01 (-40, 40)))

Idris no trae isNaN: p /= p es la prueba de NaN de IEEE 754 (/u1/t1), el único valor distinto de sí mismo, y 1 / 0 es infinito. primerInfinito recorre el Stream con un máximo de pasos, para ser total: buscar “hasta que aparezca un infinito” podría no terminar nunca. riccati e es una función de \((x, \mathcal L)\), y rk4Escalar la integra igual que integraría cualquier otra EDO escalar.

Predice. ¿Dónde desbordará Numerov desde \(x = -40\)? Desde \(\mathcal L(-10) = 0\), \(5\) y \(50\) (la exacta es \(10\)), ¿cuánto tardará Riccati en olvidar la diferencia? Por simetría, ¿qué condición sobre \(\mathcal L_L(0)\) da el estado fundamental?

Ejecuta.

U5T2> :exec printLn (-40 + 0.05 * the Double (cast (primerInfinito 2000 (numerov (fOsc 0.5) 0.05 (-40) (0, 1.0e-10)))))
-12.099999999999998
U5T2> :exec printLn [ (l0, snd (index 50 xs), snd (index 100 xs)) | l0 <- [0, 5, 50], let xs = rk4Escalar (riccati 0.5) 0.01 (-10, l0) ]
[(0.0, (9.498828106340664, 8.999999887348496)), (5.0, (9.499610671186943, 8.999999962576261)), (50.0, (9.500774985825322, 9.000000074490002))]
U5T2> :exec printLn [ (e, logDerivadaEn0 e) | e <- [0.3, 0.4, 0.5, 0.6, 0.7] ]
[(0.3, 0.31306901640373), (0.4, 0.16601101052471048), (0.5, -6.11153488927485e-13), (0.6, -0.1908119706363572), (0.7, -0.4151413001454057)]
U5T2> :exec printLn (biseccion logDerivadaEn0 0.3 0.7 - 0.5)
-3.4439118223872356e-13

Lee.

  • Numerov produce un infinito en \(x \approx -12.1\), mucho antes de llegar al centro.
  • Las tres condiciones iniciales dan \(9.4988\), \(9.4996\) y \(9.5008\) en \(x = -9.5\), y en \(x = -9\) ya coinciden con la exacta, \(9\), en ocho cifras: es la tabla de la nota conceptual. El punto fijo atractor hace que la condición inicial no importe.
  • \(\mathcal L_L(0)\) vale \(+0.313,\ +0.166,\ -6\times10^{-13},\ -0.191,\ -0.415\): valores de orden 1, sin desbordamiento. Como \(\mathcal L_R(0) = -\mathcal L_L(0)\) por simetría, la condición de empalme es \(\mathcal L_L(0) = 0\), y la bisección da \(E_0\) con un error de \(3\times10^{-13}\).

Tu turno. Integra la ecuación de Riccati con \(E = 0.4\) desde \(x = -40\) con \(h = 0.01\), \(0.05\) y \(0.06\), y mira \(\mathcal L\) en \(x = -39\) y en \(x = 0\) (por ejemplo, snd (index 20 (rk4Escalar (riccati 0.4) 0.05 (-40, 40))) y con 800). La nota conceptual dice que RK4 es inestable cerca del arranque si \(h > 0.035\). ¿Qué ves en \(x = -39\)? ¿Por qué el resultado en \(x = 0\) sale bien con \(0.05\) y no con \(0.06\)? (Con \(E = 0.5\) no se ve nada: \(\mathcal L = -x\) es una solución exacta que RK4 sigue sin error.)
