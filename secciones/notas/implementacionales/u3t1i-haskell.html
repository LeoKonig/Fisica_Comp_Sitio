Euler, Heun, Verlet: introducción a los métodos simplécticos · Implementación (Haskell)

Cómo leer esta nota. Cada pestaña corresponde a una pestaña de la nota conceptual y sigue el esquema Idea → Predice → Ejecuta → Lee → Tu turno. Todas las salidas se obtuvieron con GHCi 9.4.7.

Todas las definiciones (bloques sin ghci>) van en un solo archivo, U3T1.hs. Cárgalo con ghci U3T1.hs y usa :reload cada vez que añadas algo. Las consultas (bloques con ghci>) se escriben en GHCi, sin el ghci>.

Una idea para toda la nota: el estado es un vector. La fórmula de Euler, \(y + h\,f(y)\), solo usa dos operaciones con estados: sumarlos y multiplicarlos por un número. Si le decimos a Haskell cómo hacer esas dos cosas, el mismo integrador funcionará con un número, con un par \((q, p)\) o con cualquier estado. Una clase de tipos es justamente eso: una lista de operaciones que un tipo promete saber hacer.

Archivo U3T1.hs:

infixl 6 ^+^, ^-^
infixl 7 *^

-- Un tipo v es un "vector" si sabe sumarse y multiplicarse por un escalar.
class Vec v where
  (^+^) :: v -> v -> v
  (*^)  :: Double -> v -> v

(^-^) :: Vec v => v -> v -> v
u ^-^ w = u ^+^ ((-1) *^ w)

-- los números son vectores de una componente
instance Vec Double where
  (^+^) = (+)
  (*^)  = (*)

-- un par de vectores es un vector: se opera componente a componente
instance (Vec a, Vec b) => Vec (a, b) where
  (a, b) ^+^ (c, d) = (a ^+^ c, b ^+^ d)
  k *^ (a, b)       = (k *^ a, k *^ b)

-- el campo de velocidades de un sistema autónomo: y' = f(y)
type Campo v = v -> v

-- avanza n pasos aplicando repetidamente el mapa de un paso
pasos :: Int -> (v -> v) -> v -> v
pasos n paso y0 = iterate paso y0 !! n

Los operadores llevan ^ para no confundirlos con + y * de los números. Las líneas infixl les dan la precedencia habitual: y ^+^ h *^ k se lee \(y + (h\,k)\). La segunda instancia dice: si a y b son vectores, el par (a, b) también; así (Double, Double) es un vector sin escribir nada más. pasos n paso es la trayectoria de la nota conceptual: la iteración del mapa de un paso.

  • El espacio de fases es una variedad
  • Euler explícito: el mapa más simple
  • Heun: un orden más, el mismo defecto
  • La forma simpléctica y el campo hamiltoniano
  • Störmer-Verlet: simpléctico por construcción
  • La energía a largo plazo: el hamiltoniano modificado

Idea. Un vector tangente es un punto con una velocidad, y los números duales de /u2/t3 son exactamente eso. Con ellos calculamos el momento \(p = \partial L/\partial\dot q\) a partir del lagrangiano, sin derivar a mano: es la transformada de Legendre, que lleva de \(TQ\) (posición y velocidad) a \(T^*Q\) (posición y momento).

Añade a U3T1.hs:

{-# OPTIONS_GHC -Wno-missing-methods #-}
-- (la línea de arriba va al principio del archivo: silencia el aviso por las funciones
--  de Floating que Dual no define, como asin o cosh, que esta nota no usa)

-- número dual a + a'ε, con ε² = 0: un punto a y un vector tangente a' (ver /u2/t3)
data Dual = Dual Double Double deriving Show

instance Num Dual where
  Dual a a' + Dual b b' = Dual (a + b) (a' + b')
  Dual a a' - Dual b b' = Dual (a - b) (a' - b')
  Dual a a' * Dual b b' = Dual (a * b) (a' * b + a * b')
  abs (Dual a a')       = Dual (abs a) (a' * signum a)
  signum (Dual a _)     = Dual (signum a) 0
  fromInteger n         = Dual (fromInteger n) 0

instance Fractional Dual where
  Dual a a' / Dual b b' = Dual (a / b) ((a' * b - a * b') / (b * b))
  fromRational r        = Dual (fromRational r) 0

-- solo las funciones que usa esta nota
instance Floating Dual where
  pi              = Dual pi 0
  sin (Dual a a') = Dual (sin a) (a' * cos a)
  cos (Dual a a') = Dual (cos a) (- a' * sin a)
  exp (Dual a a') = Dual (exp a) (a' * exp a)
  log (Dual a a') = Dual (log a) (a' / a)

-- la parte tangente de un dual
tangente :: Dual -> Double
tangente (Dual _ d) = d

-- momento conjugado: p = ∂L/∂q̇, la derivada de L respecto a la velocidad
momento :: (Dual -> Dual -> Dual) -> Double -> Double -> Double
momento lag q qPunto = tangente (lag (Dual q 0) (Dual qPunto 1))

-- péndulo con m = l = g = 1: L = q̇²/2 + cos q
lagrangianoPendulo :: Floating a => a -> a -> a
lagrangianoPendulo q qPunto = qPunto * qPunto / 2 + cos q

-- partícula libre en polares: L = (ṙ² + r²θ̇²)/2
lagrangianoPolar :: Floating a => a -> a -> a -> a
lagrangianoPolar r rPunto thetaPunto = (rPunto * rPunto + r * r * thetaPunto * thetaPunto) / 2

momento lag q qPunto evalúa \(L\) con una velocidad dual, \(\dot q + 1\cdot\varepsilon\): la parte tangente del resultado es la derivada de \(L\) en la dirección de la velocidad, \(\partial L/\partial\dot q\). La posición entra con parte tangente \(0\), porque no se mueve. La función lagrangianoPendulo es polimórfica (Floating a =>), así que sirve con Double y con Dual.

Predice. Para el péndulo, \(p = \dot q\): ¿cuánto vale \(p\) en \((q, \dot q) = (1, 0.5)\)? En polares, \(p_\theta = r^2\dot\theta\): ¿cuánto vale con \(r = 2\) y \(\dot\theta = 1\)?

Ejecuta.

ghci> momento lagrangianoPendulo 1 0.5
0.5

ghci> tangente (lagrangianoPolar (Dual 2 0) (Dual 0 0) (Dual 1 1))
4.0

ghci> tangente (lagrangianoPolar (Dual 2 1) (Dual 0 0) (Dual 1 0))
2.0

Lee.

  • Para el péndulo, \(p = 0.5 = \dot q\): el momento y la velocidad valen lo mismo, aunque sean objetos distintos.
  • En polares, \(p_\theta = 4\) con \(\dot\theta = 1\). La velocidad angular y el momento angular no coinciden: \(\dot\theta\) es la componente de un vector tangente, y \(p_\theta\), la de un covector. Es el ejemplo de la nota conceptual.
  • La última consulta mueve \(r\) en lugar de \(\dot\theta\): da \(\partial L/\partial r = r\dot\theta^2 = 2\), el término centrífugo de la ecuación de Euler-Lagrange de \(r\). Con la misma \(L\) y otra semilla se obtiene otra derivada parcial.

Tu turno. Escribe el lagrangiano de un péndulo de longitud \(\ell = 2\), \(L = \frac12\ell^2\dot q^2 + \ell\cos q\), y calcula su momento en \((1, 0.5)\). ¿Coincide con \(\ell^2\dot q\)?

Idea. \(\hat\Phi_h^E(y) = y + h\,f(y)\) es una función de estado a estado. La aplicamos a \(\dot y = y\) para ver cómo rompe la ley de composición, a un punto que gira sobre un círculo para ver cómo se sale de él, y al oscilador para medir qué hace con la energía y con las áreas.

Añade a U3T1.hs:

-- Euler explícito: un paso de tamaño h
euler :: Vec v => Double -> Campo v -> v -> v
euler h f y = y ^+^ h *^ f y

-- y' = y
crecimiento :: Campo Double
crecimiento y = y

-- oscilador armónico: q' = p, p' = −q
oscilador :: Campo (Double, Double)
oscilador (q, p) = (p, -q)

energia :: (Double, Double) -> Double
energia (q, p) = (q * q + p * p) / 2

El tipo Vec v => Double -> Campo v -> v -> v dice que euler h f es un mapa v -> v para cualquier tipo de estado que sea un vector. euler 0.1 crecimiento trabaja con números y euler 0.1 oscilador, con pares.

La ley de composición

Predice. Para \(\dot y = y\), la nota conceptual muestra que dos pasos de \(h\) dan \((1+h)^2\) y un paso de \(2h\) da \(1 + 2h\). Con \(h = 0.1\), ¿cuánto vale cada uno?

Ejecuta.

ghci> pasos 2 (euler 0.1 crecimiento) 1
1.2100000000000002

ghci> euler 0.2 crecimiento 1
1.2

Lee. \(1.21\) contra \(1.2\): la diferencia es \(h^2 = 0.01\), del tamaño del error local. Dos pasos de \(h\) no son un paso de \(2h\), y por eso refinar el paso cambia el resultado.

Euler se sale del círculo

Añade a U3T1.hs:

-- un punto que gira sobre el círculo unitario: el campo (−y, x) es tangente al círculo
giro :: Campo (Double, Double)
giro (x, y) = (-y, x)

-- distancia al origen
radio :: (Double, Double) -> Double
radio (x, y) = sqrt (x * x + y * y)

Predice. El flujo exacto de giro nunca sale del círculo de radio 1. ¿A qué distancia del origen deja Euler el punto tras un paso con \(h = 0.1\)? ¿Y tras 1000?

Ejecuta.

ghci> euler 0.1 giro (1, 0)
(1.0,0.1)

ghci> radio (euler 0.1 giro (1, 0))
1.004987562112089

ghci> radio (pasos 1000 (euler 0.1 giro) (1, 0))
144.7727724325735

Lee. El primer paso llega a \((1, 0.1)\), a distancia \(\sqrt{1.01} = 1.00499\): avanza por la recta tangente y se sale de la variedad. Tras 1000 pasos, la distancia es \(1.01^{500} = 144.8\). El campo es tangente al círculo, pero el paso de Euler no lo es.

El oscilador: energía y áreas

Un paso de Euler en el oscilador es lineal, así que es una matriz. Sus columnas son las imágenes de \((1, 0)\) y \((0, 1)\), y su determinante dice por cuánto multiplica las áreas. Añade a U3T1.hs:

-- determinante de un mapa LINEAL del plano: sus columnas son paso (1,0) y paso (0,1)
determinante :: ((Double, Double) -> (Double, Double)) -> Double
determinante paso = a * d - b * c
  where
    (a, c) = paso (1, 0)
    (b, d) = paso (0, 1)

Predice. La nota conceptual da \(\det M_E = 1 + h^2\) y \(H_{1000} = 0.5\,(1.01)^{1000} = 10\,479.6\) con \(h = 0.1\). ¿Lo reproduce el código?

Ejecuta.

ghci> euler 0.1 oscilador (1, 0)
(1.0,-0.1)

ghci> determinante (euler 0.1 oscilador)
1.01

ghci> energia (pasos 1000 (euler 0.1 oscilador) (1, 0))
10479.577818906859

ghci> 0.5 * 1.01 ^ 1000
10479.577818906952

Lee.

  • Desde \((1, 0)\), Euler va a \((1, -0.1)\): es el mismo movimiento que en el círculo, con el giro en sentido contrario. Se aleja de la curva de energía \(H = 0.5\).
  • \(\det = 1.01 = 1 + h^2\): cada paso infla las áreas un \(1\,\%\).
  • La energía tras 1000 pasos coincide con la predicción \(0.5\,(1.01)^{1000}\) en 13 cifras: la energía se multiplica por \(1 + h^2\) en cada paso, exactamente. Las últimas cifras difieren porque las dos cuentas redondean distinto.

Tu turno. Calcula energia (pasos 2000 (euler 0.05 oscilador) (1, 0)), el mismo tiempo final con la mitad de paso. ¿Se arregla el problema? Compara con \(0.5\,(1 + 0.05^2)^{2000}\).

Idea. Heun promedia la pendiente del principio con la del punto al que llegaría Euler. Medimos su orden en \(\dot y = y\) y repetimos el experimento del oscilador.

Añade a U3T1.hs:

-- Heun: promedio de la pendiente inicial y la del punto predicho por Euler
heun :: Vec v => Double -> Campo v -> v -> v
heun h f y = y ^+^ (h / 2) *^ (k1 ^+^ k2)
  where
    k1 = f y
    k2 = f (y ^+^ h *^ k1)

Euler contra Heun en y’ = y

Predice. Al pasar de \(h = 0.1\) a \(h = 0.05\), ¿entre cuánto se dividirá el error de cada método en \(t = 1\)?

Ejecuta.

ghci> [ (h, pasos (round (1 / h)) (euler h crecimiento) 1, pasos (round (1 / h)) (heun h crecimiento) 1) | h <- [0.5, 0.25, 0.1, 0.05] ]
[(0.5,2.25,2.640625),(0.25,2.44140625,2.6948556900024414),(0.1,2.5937424601,2.714080846608224),(5.0e-2,2.6532977051444213,2.7171910543548843)]

ghci> [ (h, exp 1 - pasos (round (1 / h)) (euler h crecimiento) 1, exp 1 - pasos (round (1 / h)) (heun h crecimiento) 1) | h <- [0.5, 0.25, 0.1, 0.05] ]
[(0.5,0.4682818284590451,7.765682845904509e-2),(0.25,0.2768755784590451,2.3426138456603685e-2),(0.1,0.124539368359045,4.200981850821073e-3),(5.0e-2,6.498412331462378e-2,1.0907741041608077e-3)]

Lee. Es la tabla de la nota conceptual. De \(h = 0.1\) a \(0.05\), el error de Euler pasa de \(0.125\) a \(0.065\) (se divide entre \(1.9\), orden 1) y el de Heun de \(0.0042\) a \(0.0011\) (entre \(3.9\), orden 2). round (1 / h) es el número de pasos para llegar a \(t = 1\).

Heun en el oscilador

Predice. La nota conceptual da \(\det M_H = 1 + \frac{h^4}{4}\). ¿Cuánto vale con \(h = 0.1\)? ¿Qué energía habrá tras 1000 pasos?

Ejecuta.

ghci> determinante (heun 0.1 oscilador)
1.000025

ghci> energia (pasos 1000 (heun 0.1 oscilador) (1, 0))
0.5126574000594213

Lee. \(1.000025 = 1 + \frac{10^{-4}}{4}\), y la energía final es \(0.51266\), como en la nota conceptual: mucho mejor que Euler, pero sigue creciendo. Es la misma espiral hacia afuera, más lenta.

Tu turno. Usando solo determinante, predice cuántos pasos de Heun con \(h = 0.1\) hacen falta para que la energía se duplique. (Pista: \((1 + \frac{h^4}{4})^n = 2\).) Compruébalo con pasos.

Idea. Escribimos la forma simpléctica \(\omega\) como una función de dos vectores, y construimos el campo hamiltoniano \(X_H\) a partir de \(H\) y nada más: sus componentes salen del diferencial \(dH\), que calculamos con números duales. Comprobamos \(\omega(X_H, v) = dH(v)\) y la conservación de la energía, \(dH(X_H) = 0\).

Recuerda: el dual \((y, v)\) es un punto con un vector tangente; evaluar una función en él da su valor y su derivada en la dirección \(v\).

Añade a U3T1.hs:

-- la forma simpléctica ω = dq ∧ dp: área orientada del paralelogramo de lados u y v
omega :: (Double, Double) -> (Double, Double) -> Double
omega (uq, up) (vq, vp) = uq * vp - up * vq

-- el diferencial de H en el punto y, aplicado al vector v: dH(v)
diferencial :: ((Dual, Dual) -> Dual) -> (Double, Double) -> (Double, Double) -> Double
diferencial hh (q, p) (vq, vp) = tangente (hh (Dual q vq, Dual p vp))

-- el campo hamiltoniano: la solución de ω(X_H, v) = dH(v), es decir, X_H = (∂H/∂p, −∂H/∂q)
campoHamiltoniano :: ((Dual, Dual) -> Dual) -> Campo (Double, Double)
campoHamiltoniano hh y = (diferencial hh y (0, 1), - diferencial hh y (1, 0))

-- el péndulo: H = p²/2 − cos q
hamiltonianoPendulo :: Floating a => (a, a) -> a
hamiltonianoPendulo (q, p) = p * p / 2 - cos q

-- el oscilador: H = (p² + q²)/2
hamiltonianoOscilador :: Floating a => (a, a) -> a
hamiltonianoOscilador (q, p) = (p * p + q * q) / 2

diferencial hh y v evalúa \(H\) en el punto dual \(y + v\,\varepsilon\), y la parte tangente es \(dH(v)\). Con \(v = (1, 0)\) da \(\partial H/\partial q\), y con \(v = (0, 1)\), \(\partial H/\partial p\). campoHamiltoniano no conoce las ecuaciones de Hamilton: solo las componentes de \(dH\) y el resultado de la nota conceptual.

Predice. Para el péndulo, \(X_H(q, p) = (p,\ -\sin q)\). ¿Cuánto vale en \((1.5,\ 0.3)\)? ¿Qué debe dar \(dH(X_H)\)?

Ejecuta.

ghci> campoHamiltoniano hamiltonianoPendulo (1.5, 0.3)
(0.3,-0.9974949866040544)

ghci> (0.3, - sin 1.5)
(0.3,-0.9974949866040544)

ghci> campoHamiltoniano hamiltonianoOscilador (1, 0)
(0.0,-1.0)

ghci> (omega (campoHamiltoniano hamiltonianoPendulo (1.5, 0.3)) (0.2, -0.7), diferencial hamiltonianoPendulo (1.5, 0.3) (0.2, -0.7))
(-1.0501002679189103e-2,-1.0501002679189103e-2)

ghci> diferencial hamiltonianoPendulo (1.5, 0.3) (campoHamiltoniano hamiltonianoPendulo (1.5, 0.3))
0.0

ghci> (omega (1, 0) (0, 1), omega (0, 1) (1, 0), omega (0.2, -0.7) (0.2, -0.7))
(1.0,-1.0,0.0)

Lee.

  • El campo construido a partir de \(H\) es \((0.3,\ -0.99749)\), idéntico a \((p,\ -\sin q)\): las ecuaciones de Hamilton salieron de \(\iota_{X_H}\omega = dH\), sin escribirlas. Para el oscilador, \(X_H(1, 0) = (0, -1)\): el campo oscilador de la pestaña de Euler.
  • Con un vector cualquiera \(v = (0.2, -0.7)\), \(\omega(X_H, v)\) y \(dH(v)\) dan el mismo número: es la definición de \(X_H\), comprobada en un caso.
  • \(dH(X_H) = 0\): la energía no cambia a lo largo de su propio campo. Es la antisimetría de \(\omega\), que también se ve en la última consulta: \(\omega\) cambia de signo al intercambiar los vectores, y \(\omega(v, v) = 0\).

Tu turno. Construye con campoHamiltoniano el campo de \(H = \frac12p^2 + \frac12q^2 + \frac14q^4\) (el oscilador de Duffing) y compáralo en \((1, 2)\) con \((p,\ -q - q^3)\).

Idea. Verlet alterna medio impulso, un paso de movimiento libre y otro medio impulso: los flujos exactos de \(V\) y de \(T\). Lo escribimos para cualquier fuerza \(F(q) = -V'(q)\), comprobamos un paso de la nota conceptual y medimos su determinante. Luego comprobamos que también es simpléctico en el péndulo, que no es lineal, calculando su mapa tangente con números duales.

Recuerda: determinante paso es el factor por el que un paso lineal multiplica las áreas; un mapa del plano es simpléctico si ese factor es \(1\).

Añade a U3T1.hs:

-- Störmer-Verlet para H = p²/2 + V(q); fuerza q = −V'(q)
verlet :: Fractional a => a -> (a -> a) -> (a, a) -> (a, a)
verlet h fuerza (q, p) = (q', p')
  where
    pMedio = p + (h / 2) * fuerza q        -- medio impulso
    q'     = q + h * pMedio                -- movimiento libre durante h
    p'     = pMedio + (h / 2) * fuerza q'  -- otro medio impulso

-- la fuerza del oscilador armónico, F = −q
resorte :: Num a => a -> a
resorte q = -q

Verlet no recibe un Campo, sino la fuerza: necesita la separación \(H = T(p) + V(q)\), porque cada sub-paso es el flujo exacto de una de las dos partes. Su tipo, Fractional a =>, permite usarlo con Double y también con Dual.

Predice. La nota conceptual calcula un paso desde \((1, 0)\) con \(h = 0.1\): \((0.995,\ -0.09975)\). ¿Y el determinante?

Ejecuta.

ghci> verlet 0.1 resorte (1, 0)
(0.995,-9.975e-2)

ghci> (cos 0.1, - sin 0.1)
(0.9950041652780258,-9.983341664682815e-2)

ghci> determinante (verlet 0.1 resorte)
1.0

ghci> [ determinante paso ^ 1000 | paso <- [euler 0.1 oscilador, heun 0.1 oscilador, verlet 0.1 resorte] ]
[20959.155637813903,1.0253148001188277,1.0]

Lee.

  • El paso coincide con el cálculo a mano de la nota conceptual, y con el exacto en tres cifras.
  • \(\det M_V = 1\): Verlet conserva las áreas, como el flujo exacto.
  • La última lista es el factor de área tras 1000 pasos: Euler infla una región unas \(21\,000\) veces, Heun un \(2.5\,\%\), y Verlet la deja con el mismo área. Fíjate en que la lista contiene funciones (paso): en Haskell, los integradores son valores como cualquier otro.

Simpléctico también en el péndulo

En el péndulo los pasos no son lineales, así que no tienen “una” matriz: en cada punto tienen un mapa tangente, cuya matriz (el jacobiano) cambia de un punto a otro. Lo calculamos con dos pasadas de duales, una por columna, como en /u2/t3. Añade a U3T1.hs:

-- los números duales también son vectores: k·(a + a'ε) = ka + ka'ε
instance Vec Dual where
  (^+^)  = (+)
  k *^ d = Dual k 0 * d

-- péndulo: fuerza −sin q, y el mismo sistema como campo, para Euler y Heun
pendulo :: Floating a => a -> a
pendulo q = - sin q

campoPendulo :: Floating a => Campo (a, a)
campoPendulo (q, p) = (p, - sin q)

-- el mapa tangente de un paso en el punto y: sus columnas son las imágenes de (1,0) y (0,1)
jacobiano :: ((Dual, Dual) -> (Dual, Dual)) -> (Double, Double) -> ((Double, Double), (Double, Double))
jacobiano paso (q, p) = ((tangente a, tangente c), (tangente b, tangente d))
  where
    (a, c) = paso (Dual q 1, Dual p 0)
    (b, d) = paso (Dual q 0, Dual p 1)

-- ω(Dφ e_q, Dφ e_p): el área del cuadrado unitario tras el paso; 1 si el paso es simpléctico ahí
areaTangente :: ((Dual, Dual) -> (Dual, Dual)) -> (Double, Double) -> Double
areaTangente paso y = omega col1 col2
  where
    (col1, col2) = jacobiano paso y

jacobiano paso y empuja los dos vectores de la base con el paso: es el mapa tangente \(D\varphi\) de la nota conceptual, la elevación \(Tf\) de /u2/t3. areaTangente aplica \(\omega\) a las dos columnas: el área en la que el paso convierte el cuadrado unitario.

Predice. En \((1.5, 0)\) y en \((2.5, 0.5)\), con \(h = 0.1\), ¿qué área dará cada método?

Ejecuta.

ghci> [ areaTangente (verlet 0.1 pendulo) y | y <- [(1.5, 0), (2.5, 0.5)] ]
[1.0,0.9999999999999999]

ghci> [ areaTangente (heun 0.1 campoPendulo) y | y <- [(1.5, 0), (2.5, 0.5)] ]
[1.0000001250937924,1.000016624802258]

ghci> [ areaTangente (euler 0.1 campoPendulo) y | y <- [(1.5, 0), (2.5, 0.5)] ]
[1.000707372016677,0.9919885638445307]

ghci> [ 1 + 0.01 * cos q | q <- [1.5, 2.5] ]
[1.000707372016677,0.9919885638445307]

Lee.

  • Verlet: área \(1\) en los dos puntos, salvo el último bit de redondeo. El argumento de la nota conceptual (cada sub-paso es un flujo hamiltoniano exacto) no usa la linealidad, y el cálculo lo confirma.
  • Heun: áreas distintas de \(1\), y distintas en cada punto.
  • Euler: su jacobiano es \(\begin{pmatrix}1 & h\\ -h\cos q & 1\end{pmatrix}\), de determinante \(1 + h^2\cos q\), la última lista. En \(q = 1.5\) infla las áreas y en \(q = 2.5\) las encoge: un mapa que no es simpléctico puede equivocarse en los dos sentidos.

Tu turno. Escribe verletMalo, que da el impulso completo antes del movimiento libre: p' = p + h * fuerza q y luego q' = q + h * p'. Es el método de Euler simpléctico. Calcula su areaTangente en el péndulo. ¿Es simpléctico? ¿Y la energía tras 1000 pasos, en el oscilador?

Idea. Verlet no conserva la energía \(H\), pero sí una vecina, \(\tilde H = H - \frac{h^2}{8}q^2\). Lo comprobamos, medimos la banda en que oscila \(H\), y vemos el caso no lineal del péndulo, integrado en la carta del ángulo.

Recuerda: con Euler y Heun, la energía del oscilador crece en cada paso.

Añade a U3T1.hs:

-- el hamiltoniano modificado del oscilador: H̃ = p²/2 + (1 − h²/4) q²/2
energiaModificada :: Double -> (Double, Double) -> Double
energiaModificada h (q, p) = p * p / 2 + (1 - h * h / 4) * q * q / 2

-- máxima desviación de una cantidad e a lo largo de n pasos
desviacionMax :: ((Double, Double) -> Double) -> Int -> ((Double, Double) -> (Double, Double)) -> (Double, Double) -> Double
desviacionMax e n paso y0 = maximum [ abs (e y - e y0) | y <- take (n + 1) (iterate paso y0) ]

desviacionMax recibe la cantidad que se quiere vigilar (energia, energiaModificada h, …) y el mapa de un paso: es una función de orden superior sobre integradores.

La banda de energía del oscilador

Predice. La nota conceptual dice que \(H\) oscila en \([0.49875,\ 0.5]\) con \(h = 0.1\), y que \(\tilde H\) se conserva exactamente. ¿Cuánto se desviará \(\tilde H\) en 1000 pasos?

Ejecuta.

ghci> let es = map energia (take 1001 (iterate (verlet 0.1 resorte) (1, 0)))

ghci> (minimum es, maximum es)
(0.498750004719322,0.5)

ghci> energia (pasos 1000 (verlet 0.1 resorte) (1, 0))
0.4997239159394073

ghci> desviacionMax (energiaModificada 0.1) 1000 (verlet 0.1 resorte) (1, 0)
1.27675647831893e-15

Lee.

  • La energía nunca sale de la banda \([0.49875,\ 0.5] = [\frac12 - \frac{h^2}{8},\ \frac12]\): oscila, pero no deriva. El valor final, \(0.49972\), es solo un punto dentro de la banda.
  • \(\tilde H\) se desvía \(1.3\times10^{-15}\) en 1000 pasos: unos pocos redondeos de \(\varepsilon_{\text{mach}}\) (/u1/t1). Es una cantidad conservada del mapa numérico: la órbita se queda en una curva de nivel de \(\tilde H\).

El péndulo, un caso no lineal

Usamos pendulo y campoPendulo de la pestaña de Verlet. Añade a U3T1.hs:

energiaPendulo :: (Double, Double) -> Double
energiaPendulo (q, p) = p * p / 2 - cos q

Predice. Desde \(q_0 = 1.5\) hasta \(t = 1000\), la nota conceptual da para Verlet una desviación máxima de \(1.96\times10^{-3}\) con \(h = 0.1\). ¿Cuánto con \(h = 0.05\)? ¿Y la deriva final de Heun y de Euler?

Ejecuta.

ghci> desviacionMax energiaPendulo 10000 (verlet 0.1 pendulo) (1.5, 0)
1.9636901062967255e-3

ghci> desviacionMax energiaPendulo 20000 (verlet 0.05 pendulo) (1.5, 0)
4.908592119125116e-4

ghci> map (\n -> energiaPendulo (pasos n (heun 0.1 campoPendulo) (1.5, 0)) - energiaPendulo (1.5, 0)) [1000, 2500, 5000, 10000]
[1.2795547385214809e-2,3.31643944741241e-2,6.732279057751966e-2,0.13647129690992035]

ghci> energiaPendulo (pasos 10000 (euler 0.1 campoPendulo) (1.5, 0)) - energiaPendulo (1.5, 0)
47.908994678539386

Lee.

  • Verlet: al reducir \(h\) a la mitad, la desviación máxima se divide entre \(4\). Es \(O(h^2)\), como predice \(\tilde H = H + O(h^2)\).
  • Heun: la deriva crece en proporción al tiempo, unas \(0.013\) por cada 100 unidades. No se detiene.
  • Euler: la energía subió casi \(48\) unidades. Con \(H_0 = -\cos 1.5 \approx -0.07\), el péndulo numérico ya da vueltas completas.

La carta del ángulo

Cuando el péndulo da vueltas completas, \(q\) crece sin límite, aunque \(q\) y \(q + 2\pi\) sean la misma posición. Para quedarnos en la carta \((-\pi, \pi]\) del círculo, reducimos el ángulo después de cada paso. Añade a U3T1.hs:

-- lleva un ángulo a la carta [−π, π]: le resta el múltiplo de 2π más cercano
aCarta :: Double -> Double
aCarta q = q - 2 * pi * fromIntegral (round (q / (2 * pi)) :: Integer)

-- un paso de Verlet seguido del cambio de carta
verletCarta :: Double -> (Double -> Double) -> (Double, Double) -> (Double, Double)
verletCarta h fuerza y = (aCarta q', p')
  where
    (q', p') = verlet h fuerza y

Predice. Desde \((0, 2.5)\), con \(H = 2.125 > 1\), el péndulo da vueltas. Tras 1000 pasos de \(h = 0.1\), ¿dónde estará \(q\) sin reducir y reduciendo en cada paso? ¿Describen el mismo punto del cilindro?

Ejecuta.

ghci> pasos 1000 (verlet 0.1 pendulo) (0, 2.5)
(197.27183876336636,1.634109416465352)

ghci> pasos 1000 (verletCarta 0.1 pendulo) (0, 2.5)
(2.4930942408008954,1.6341094164648102)

ghci> aCarta (fst (pasos 1000 (verlet 0.1 pendulo) (0, 2.5))) - fst (pasos 1000 (verletCarta 0.1 pendulo) (0, 2.5))
-1.7004175845158898e-12

Lee. Sin reducir, \(q\) se fue lejos: el péndulo dio decenas de vueltas. Reduciendo en cada paso, \(q\) se queda en \([-\pi, \pi]\), con el mismo \(p\). Reducido al final, el primer resultado da el mismo ángulo que el segundo, salvo un error de redondeo diminuto: las dos formas de calcular describen el mismo punto del cilindro \(T^*S^1\), porque la fuerza \(-\sin q\) no cambia al sumar \(2\pi\).

Simpléctico no significa exacto

Predice. En \(t = 100\), ¿estará Verlet cerca del punto exacto \((\cos 100,\ -\sin 100)\)?

Ejecuta.

ghci> pasos 1000 (verlet 0.1 resorte) (1, 0)
(0.8826849673165411,0.4693773325930976)

ghci> (cos 100, - sin 100)
(0.8623188722876839,0.5063656411097588)

Lee. Verlet está sobre la curva correcta, pero adelantado: la órbita numérica gira con frecuencia \(\approx 1 + \frac{h^2}{24}\), y en \(t = 100\) lleva unos \(0.04\) rad de ventaja. Pertenecer al grupo de los mapas simplécticos garantiza el comportamiento a largo plazo, no la posición en un instante.

Tu turno. Calcula la fase de cada punto con atan2 p q y comprueba que la diferencia es \(\approx 100 \cdot \frac{h^2}{24}\).
