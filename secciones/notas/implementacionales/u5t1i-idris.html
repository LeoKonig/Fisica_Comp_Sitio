Las definiciones (bloques sin prompt) van en un archivo U5T1.idr. Las consultas (con el prompt U5T1>) se escriben en el REPL, sin el prompt. Abre el REPL con idris2 U5T1.idr y usa :r para recargar el archivo cuando añadas algo. Necesitas el archivo Exacto.idr de la implementación de /u1/t1 en la misma carpeta.

Numerov como despliegue. Como los integradores de la Unidad 3, Numerov es una función pura de estado a estado, y la solución es su iteración: un Stream, la sucesión infinita de /u3/t5. El estado lleva los dos últimos valores de \(\psi\) y la posición, como pide la nota conceptual, para que \(f\) siempre se evalúe en el punto correcto. Al final de la primera pestaña usamos los tipos dependientes para atar la malla y la solución. Usamos \(\hbar = m = 1\): la ecuación es \(\psi'' = f(x)\,\psi\), con \(f = 2(V - E)\).

Archivo U5T1.idr:

module U5T1

import Exacto
import Data.List
import Data.Stream
import Data.Vect

%default total

-- el estado del despliegue: ψ_{n-1}, ψ_n y x_n, con ψ_n en x_n y ψ_{n-1} en x_n − h
record Estado where
  constructor MkEstado
  anterior : Double
  actual   : Double
  posicion : Double

-- un paso de Numerov para ψ'' = f(x) ψ; conserva el invariante
pasoNumerov : (Double -> Double) -> Double -> Estado -> Estado
pasoNumerov f h (MkEstado pm p x) =
  let w : Double -> Double
      w y = 1 - h * h / 12 * f y                         -- el peso w(x)
  in MkEstado p ((2 * p * (1 + 5 * h * h / 12 * f x) - pm * w (x - h)) / w (x + h)) (x + h)

-- la sucesión infinita ψ_0, ψ_1, ψ_2, … desde x0, con los dos valores iniciales
numerov : (Double -> Double) -> Double -> Double -> (Double, Double) -> Stream Double
numerov f h x0 (p0, p1) = p0 :: map actual (iterate (pasoNumerov f h) (MkEstado p0 p1 (x0 + h)))

-- los n primeros elementos de un Stream, como vector de longitud n
tomar : (n : Nat) -> Stream a -> Vect n a
tomar Z     _         = []
tomar (S k) (x :: xs) = x :: tomar k xs

-- el número de pasos de tamaño h que hay en una distancia d (redondeado)
pasos : Double -> Double -> Nat
pasos d h = cast (the Integer (cast (floor (d / h + 0.5))))

El estado inicial es MkEstado p0 p1 (x0 + h): \(\psi_1\) vive en \(x_0 + h\) y \(\psi_0\) un paso antes, que es el invariante. Cada pasoNumerov calcula \(\psi_{n+1}\) y avanza la posición. numerov no sabe nada del problema físico: recibe la función f (es una función de orden superior), el paso, el punto inicial y los dos primeros valores. index n toma el elemento \(n\) del Stream (el valor en \(x_0 + nh\)), y tomar n sus \(n\) primeros, como un vector Vect n cuya longitud está en el tipo. Idris no trae round, así que pasos redondea con floor (· + 0.5) y convierte a Nat. Como Data.Vect también define listas literales […], en las consultas escribimos the (List Double) [...] para que Idris sepa que es una lista.

  • El arranque: de dónde sale ψ₁
  • Inestabilidad en regiones evanescentes

Idea. Comprobamos la recurrencia con \(\psi'' = -\psi\), cuya solución es \(\sin x\): el coeficiente \(c\) de la nota conceptual (también en Racional), el primer paso, y la comparación con Verlet y RK4. Después provocamos los dos errores silenciosos de la nota, y vemos qué parte de la alineación pueden vigilar los tipos.

Recuerda: con \(f\) constante, Numerov es \(\psi_{n+1} = c\,\psi_n - \psi_{n-1}\), y la solución exacta cumple lo mismo con \(c = 2\cos h\).

-- el coeficiente c de Numerov y de Verlet para f = −1, en cualquier tipo fraccionario
coefNumerov : Fractional a => Neg a => a -> a
coefNumerov h = 2 * (1 - 5 * h * h / 12) / (1 + h * h / 12)

coefVerlet : Double -> Double
coefVerlet h = 2 - h * h

-- Verlet: la misma recurrencia sin el término de Numerov (ver /u3/t1)
verlet : (Double -> Double) -> Double -> Double -> (Double, Double) -> Stream Double
verlet f h x0 (p0, p1) = p0 :: map actual (iterate paso (MkEstado p0 p1 (x0 + h)))
  where
    paso : Estado -> Estado
    paso (MkEstado pm p x) = MkEstado p ((2 + h * h * f x) * p - pm) (x + h)

-- RK4 (ver /u3/t3) para el sistema de primer orden (ψ, ψ'), con ψ'' = f ψ
rk4 : (Double -> Double) -> Double -> Double -> (Double, Double) -> Stream Double
rk4 f h x0 y0 = map (fst . snd) (iterate paso (x0, y0))
  where
    campo : Double -> (Double, Double) -> (Double, Double)
    campo x (p, d) = (d, f x * p)
    mas : (Double, Double) -> Double -> (Double, Double) -> (Double, Double)
    mas (a, b) k (c, d) = (a + k * c, b + k * d)
    paso : (Double, (Double, Double)) -> (Double, (Double, Double))
    paso (x, y) =
      let k1 = campo x y
          k2 = campo (x + h / 2) (mas y (h / 2) k1)
          k3 = campo (x + h / 2) (mas y (h / 2) k2)
          k4 = campo (x + h) (mas y h k3)
      in (x + h, mas (mas (mas (mas y (h / 6) k1) (h / 3) k2) (h / 3) k3) (h / 6) k4)

-- error en x = 10 de cada método para ψ'' = −ψ, ψ = sin x
erroresEn10 : Double -> (Double, Double, Double)
erroresEn10 h =
  let n = pasos 10 h
      err : Stream Double -> Double
      err ps = abs (index n ps - sin 10)
  in (err (verlet (const (-1)) h 0 (0, sin h)), err (rk4 (const (-1)) h 0 (0, 1)), err (numerov (const (-1)) h 0 (0, sin h)))

rk4 necesita \(\psi'(0) = 1\) en lugar de \(\psi_1\), porque es un método de un paso para el sistema de primer orden; su estado es (x, (ψ, ψ')), y fst . snd se queda con \(\psi\). coefNumerov es polimórfica: con Racional da la fracción exacta.

Predice. La nota conceptual da \(c_{\text{Numerov}} - 2\cos h \approx 4\times10^{-9}\) y \(c_{\text{Verlet}} - 2\cos h \approx 8\times10^{-6}\) con \(h = 0.1\). ¿Qué es \(c_{\text{Numerov}}\) como fracción exacta, con \(h = \frac1{10}\)? ¿Qué orden global tendrá cada método?

Lee.

  • Las diferencias son \(-4.2\times10^{-9}\) y \(-8.3\times10^{-6}\), las de la nota conceptual; la primera es \(-\frac{h^6}{240}\).
  • En Racional, \(c_{\text{Numerov}} = \frac{2390}{1201}\): una fracción, porque la recurrencia solo suma, multiplica y divide.
  • El tercer valor, \(\psi_2 = 0.19866933\), es \(\sin 0.2\), y \(\psi(1) = 0.8414709\) coincide con \(\sin 1\) en siete cifras.
  • Los errores en \(x = 10\) son los de la tabla de la nota conceptual (Verlet, RK4, Numerov; Idris escribe la terna como (a, (b, c))). Al dividir \(h\) entre 2, Verlet se divide entre 4 (orden 2) y RK4 y Numerov entre 16 (orden 4), con Numerov unas 4.5 veces más preciso.

Dos errores silenciosos, y lo que pueden vigilar los tipos

Añade a U5T1.idr:

-- la recurrencia de los libros que escriben ψ'' = −k² ψ, con los signos cambiados
numerovK : (Double -> Double) -> Double -> Double -> (Double, Double) -> Stream Double
numerovK k2 h x0 (p0, p1) = p0 :: map actual (iterate paso (MkEstado p0 p1 (x0 + h)))
  where
    w : Double -> Double
    w y = 1 + h * h / 12 * k2 y
    paso : Estado -> Estado
    paso (MkEstado pm p x) = MkEstado p ((2 * p * (1 - 5 * h * h / 12 * k2 x) - pm * w (x - h)) / w (x + h)) (x + h)

-- el desfase: f se evalúa un paso adelante de donde debería
numerovDesfasado : (Double -> Double) -> Double -> Double -> (Double, Double) -> Stream Double
numerovDesfasado f h = numerov (\x => f (x + h)) h

-- el oscilador con E = 1/2: f = x² − 1, solución exacta e^{−x²/2}
fOscilador : Double -> Double
fOscilador x = x * x - 1

-- errores en x = 1 con la malla bien alineada y con el desfase
erroresDesfase : Double -> (Double, Double)
erroresDesfase h =
  let n  = pasos 1 h
      p1 = exp (-(h * h / 2))
  in (abs (index n (numerov fOscilador h 0 (1, p1)) - exp (-0.5)),
      abs (index n (numerovDesfasado fOscilador h 0 (1, p1)) - exp (-0.5)))

-- la malla y la solución como vectores con su longitud en el tipo
malla : (n : Nat) -> Double -> Double -> Vect n Double
malla n x0 h = tomar n (iterate (+ h) x0)

solucion : (n : Nat) -> (Double -> Double) -> Double -> Double -> (Double, Double) -> Vect n Double
solucion n f h x0 ini = tomar n (numerov f h x0 ini)

-- emparejar posición y valor: solo acepta vectores de la MISMA longitud n
tabla : Vect n Double -> Vect n Double -> Vect n (Double, Double)
tabla = zip

numerovDesfasado reutiliza numerov con otra función: \x => f (x + h) es \(f\) desplazada un paso, el error de quien escribe f x en lugar de f (x + h). tomar (definida al principio) devuelve un Vect n: su tipo dice que el resultado tiene exactamente n elementos, y el compilador lo comprueba. El tipo de tabla exige que la malla y la solución tengan la misma longitud.

Predice. Si se usa numerovK con la función \(f\) (en lugar de \(k^2 = -f\)), ¿qué ecuación se resuelve? Con el desfase, ¿seguirá el error dividiéndose entre 16? ¿Aceptará Idris tabla con una malla de 3 puntos y una solución de 4? ¿Y con la cola (tail) de una solución de 4, que tiene 3 elementos pero desplazados?

Lee.

  • Con \(k^2 = -f = 1\), la convención de los libros da \(\sin 1 = 0.84147\). Mezclando convenciones, con \(f = -1\) puesto donde iba \(k^2\), da \(1.17129\): la solución, muy precisa, de \(\psi'' = +\psi\).
  • Con la malla bien alineada, el error en \(x = 1\) se divide entre unos 15 al dividir \(h\): orden 4. Con el desfase, solo entre 2: orden 1, con errores cien mil veces mayores.
  • tabla con 3 y 3 da los pares (posición, valor) correctos. Con 3 y 4, Idris rechaza la expresión: no puede unificar 3 con 4 (los Nat se comparan como S (S (S Z)) y S (S (S (S Z))); al quitar las tres S comunes quedan 0 y 1, de ahí el mensaje). Un error de longitud no llega a ejecutarse.
  • Pero con la cola de una solución de 4, los tipos coinciden (las dos tienen 3 elementos) y la tabla sale desplazada: en \(x = 0\) aparece \(\psi(0.1)\). El tipo Vect n vigila la longitud, no el significado de cada posición. La defensa contra un desplazamiento es la del estado de numerov: que cada valor viaje junto con su posición.

Tu turno. Escribe numerovConPosicion : (Double -> Double) -> Double -> Double -> (Double, Double) -> Stream (Double, Double), que devuelva los pares (posición, valor) tomando ambos del mismo Estado. ¿Por qué con esta versión el error de la cola desplazada ya no se puede escribir?

Idea. Medimos el orden del método completo con los tres arranques de la nota conceptual en el caso par, y comprobamos que, en una pared, la elección de \(\psi_1\) solo cambia la normalización.

Recuerda: con paridad par, \(\psi_1 = \psi_0\big[1 + \frac{h^2}{2}f_0 + \frac{h^4}{24}(f_0^2 + f''_0)\big]\); truncar en \(h^2\) baja el método a orden 3.

Añade a U5T1.idr:

-- arranques para estados pares, con ψ0 = 1: truncado en h², y con el término en h⁴
arranque2 : Double -> Double -> Double -> Double
arranque2 f0 _ h = 1 + h * h / 2 * f0

arranque4 : Double -> Double -> Double -> Double
arranque4 f0 f2 h = 1 + h * h / 2 * f0 + h * h * h * h / 24 * (f0 * f0 + f2)

-- error en x = 10 para ψ'' = −ψ, ψ = cos x, con el ψ1 dado
errorCoseno : Double -> Double -> Double
errorCoseno h p1 = abs (index (pasos 10 h) (numerov (const (-1)) h 0 (1, p1)) - cos 10)

-- regla del trapecio (ver /u2/t4) sobre valores equiespaciados
trapecio : Double -> List Double -> Double
trapecio h ys = h * (sum ys - (fromMaybe 0 (head' ys) + fromMaybe 0 (last' ys)) / 2)

-- divide entre la raíz de ∫ψ², para que la probabilidad total sea 1
normalizar : Double -> List Double -> List Double
normalizar h ps = let c = sqrt (trapecio h (map (\p => p * p) ps)) in map (/ c) ps

-- el pozo [0, 1] con E = π²/2: f = −π², 100 pasos de h = 0.01
pozo : Double -> List Double
pozo p1 = take 101 (numerov (const (-(pi * pi))) 0.01 0 (0, p1))

head' y last' devuelven un Maybe (la lista podría estar vacía), y fromMaybe 0 lo resuelve; así trapecio es total.

Predice. Para \(h = 0.2, 0.1, 0.05\), ¿cuánto se divide el error de cada arranque? En el pozo, ¿cambia \(\psi(0.5)\) normalizada si \(\psi_1 = 10^{-3}\) o \(\psi_1 = 7\)?

Lee.

  • Es la tabla de la nota conceptual. Con el arranque truncado, el error baja de \(2.0\times10^{-4}\) a \(2.4\times10^{-5}\) y a \(2.9\times10^{-6}\): se divide entre 8, orden 3. Con el término en \(h^4\), el error es casi el mismo que con el valor exacto \(\cos h\), y se divide entre 16: orden 4.
  • En el pozo, los dos arranques dan, normalizados, \(\psi(0.5) = 1.41421\) (Just, porque getAt también devuelve un Maybe), el \(\sqrt2\) del estado \(\sqrt2\sin\pi x\). \(\psi_1\) solo fijaba la escala.
  • Sin normalizar, \(\psi(1) = -2\times10^{-10}\), frente a un máximo de \(0.03\) en el centro: con el \(E\) exacto, la solución llega a la otra pared en cero, salvo el error de Numerov. En /u5/t2, ese valor será la función que hay que anular.

Tu turno. Repite la tabla del arranque para el oscilador par \(\psi'' = (x^2 - 1)\psi\), con \(\psi_0 = 1\), \(f_0 = -1\) y \(f''_0 = 2\), comparando en \(x = 1\) con \(e^{-1/2}\). ¿Importa aquí el término \(f''_0\)?

Idea. Seguimos la solución decreciente \(e^{-x}\) de \(\psi'' = \psi\) hacia adelante y hacia atrás, y medimos el tamaño \(\delta\) de la componente parásita que la destruye.

Recuerda: la proporción entre la parte parásita y la buscada crece como \(\delta\,e^{2x}\); integrar en el sentido en que la solución buscada crece la mantiene controlada.

-- e^{−x} con ψ'' = ψ, hacia adelante desde 0 y hacia atrás desde 40, con h = 0.05
adelante : Stream Double
adelante = numerov (const 1) 0.05 0 (1, exp (-0.05))
