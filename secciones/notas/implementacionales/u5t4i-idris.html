Un funcional es una función de orden superior. El cociente de Rayleigh recibe una función de onda y devuelve un número. En Idris, rayleigh recibirá literalmente una función \(\psi\) y un potencial \(V\), y nada más: la derivada \(\psi'\) la calculará sola, con los números duales de /u2/t3, y las integrales sobre toda la recta con un cambio de variable. La última pestaña es la razón de que el curso tenga una versión en Idris: ahí enunciamos la cota variacional como un tipo, y demostramos una parte.

module U5T4

%default total

-- números duales (ver /u2/t3): MkDual v d representa v + d·ε, con ε² = 0
record Dual where
  constructor MkDual
  val : Double
  der : Double

Num Dual where
  MkDual a a' + MkDual b b' = MkDual (a + b) (a' + b')
  MkDual a a' * MkDual b b' = MkDual (a * b) (a' * b + a * b')
  fromInteger n = MkDual (fromInteger n) 0

Neg Dual where
  negate (MkDual a a') = MkDual (negate a) (negate a')
  MkDual a a' - MkDual b b' = MkDual (a - b) (a' - b')

Fractional Dual where
  MkDual a a' / MkDual b b' = MkDual (a / b) ((a' * b - a * b') / (b * b))

-- un Double como constante dual (derivada 0), y la exponencial con su regla de la cadena
constante : Double -> Dual
constante a = MkDual a 0

expD : Dual -> Dual
expD (MkDual a a') = MkDual (exp a) (a' * exp a)

-- (f(x), f'(x)) de una vez, evaluando f en x + ε
valorYDerivada : (Dual -> Dual) -> Double -> (Double, Double)
valorYDerivada f x = let MkDual v d = f (MkDual x 1) in (v, d)

-- ∫ g(x) dx sobre toda la recta, con x = tan θ y la regla del punto medio en θ ∈ (−π/2, π/2)
integralReal : (Double -> Double) -> Double
integralReal g =
  let n  = the Nat 1000
      dt = pi / cast n
  in dt * sum [ g (tan t) / (cos t * cos t) | k <- [0 .. n `minus` 1], let t = -pi / 2 + (cast k + 0.5) * dt ]

integralReal resuelve un problema práctico: las funciones de onda viven en toda la recta, y cortarlas en \([-L, L]\) pierde las colas. Con \(x = \tan\theta\), \(dx = \frac{d\theta}{\cos^2\theta}\), toda la recta se vuelve el intervalo finito \((-\frac\pi2, \frac\pi2)\); la regla del punto medio (la del trapecio de /u2/t4, pero evaluando en el centro de cada subintervalo) nunca toca los extremos, donde \(\tan\theta\) sería infinito. Data.Nat y Data.So se usarán en la última pestaña.

Idea. Escribimos el cociente de Rayleigh como una función que recibe \(\psi\) y \(V\), lo evaluamos en las tres familias de prueba de la nota conceptual, y lo minimizamos en su parámetro. Medimos también que el error de la energía es de segundo orden.

Recuerda: \(\mathcal R[\psi] = \frac{\int\left(\frac12\psi'^2 + V\psi^2\right)dx}{\int\psi^2\,dx}\), usando la forma integrada por partes de la energía cinética.

Añade a U5T4.idr:

-- el cociente de Rayleigh de ψ con el potencial V: un funcional
rayleigh : (Dual -> Dual) -> (Double -> Double) -> Double
rayleigh psi v = integralReal energia / integralReal norma2
  where
    energia : Double -> Double
    energia x = let (p, d) = valorYDerivada psi x in 0.5 * d * d + v x * p * p
    norma2 : Double -> Double
    norma2 x = let (p, _) = valorYDerivada psi x in p * p

-- las familias de prueba
gaussiana : Double -> Dual -> Dual
gaussiana a x = expD (-(constante a) * x * x)

lorentziana : Double -> Dual -> Dual
lorentziana b x = 1 / (x * x + constante (b * b))

-- mínimo de f en [a, b] por sección áurea: (punto, valor)
minimizar : (Double -> Double) -> Double -> Double -> (Double, Double)
minimizar f a0 b0 = ir 50 a0 b0
  where
    r : Double
    r = (sqrt 5 - 1) / 2                              -- 0.618…, la razón áurea
    ir : Nat -> Double -> Double -> (Double, Double)
    ir Z     a b = let m = (a + b) / 2 in (m, f m)
    ir (S k) a b = let c = b - r * (b - a)
                       d = a + r * (b - a)
                   in if f c < f d then ir k a d else ir k c b

rayleigh no sabe qué es una gaussiana: recibe cualquier función Dual -> Dual, y valorYDerivada obtiene \(\psi\) y \(\psi'\) en cada punto. minimizar es la bisección de /u2/t6 para mínimos: compara \(f\) en dos puntos interiores y descarta el tercio del intervalo donde el mínimo no puede estar; con los puntos en la razón áurea, el intervalo se reduce por \(0.618\) en cada paso.

  • rayleigh reproduce la fórmula en 15 cifras: es la tabla de errores de segundo orden de la nota conceptual (\(0.5,\ 0.50227,\ 0.50833,\ 0.54167\)).
  • El mínimo de la gaussiana es \(\mathcal R = 0.5\) exacto. Idea. Con la función de prueba \(\psi = \phi_1 + t\,\phi_2\) de los dos polinomios de /u5/t3, el cociente es una función ordinaria \(\mathcal R(t)\). Buscamos su mínimo y su máximo directamente, y comprobamos que son los valores propios generalizados y que \((1, t)\) son sus vectores propios. Matriz : Type -> Type
Matriz a = List (List a)

punto : Num a => List a -> List a -> a
punto u v = sum (zipWith (*) u v)

matVec : Num a => Matriz a -> List a -> List a
matVec m v = [ punto f v | f <- m ]

-- las matrices de los dos polinomios (ver /u5/t3), en cualquier tipo fraccionario
hPol : Fractional a => Matriz a
hPol = [[1 / 6, 1 / 30], [1 / 30, 1 / 105]]

sPol : Fractional a => Matriz a
sPol = [[1 / 30, 1 / 140], [1 / 140, 1 / 630]]

-- el cociente de Rayleigh restringido: cᵀHc / cᵀSc
cocienteR : Fractional a => Matriz a -> Matriz a -> List a -> a
cocienteR h s c = punto c (matVec h c) / punto c (matVec s c)

rDeT : Double -> Double
rDeT t = cocienteR hPol sPol [1, t]

-- las dos raíces de det(H − E S) = 0, una cuadrática a E² + b E + c = 0
propiosGeneralizados2 : Matriz Double -> Matriz Double -> (Double, Double)
propiosGeneralizados2 [[h11, h12], [_, h22]] [[s11, s12], [_, s22]] =
  let a = s11 * s22 - s12 * s12
      b = -(h11 * s22 + h22 * s11 - 2 * h12 * s12)
      c = h11 * h22 - h12 * h12
      r = sqrt (b * b - 4 * a * c)
  in ((-b - r) / (2 * a), (-b + r) / (2 * a))
propiosGeneralizados2 _ _ = (0, 0)

-- H c − R(c) S c: cero si c es un vector propio generalizado
residuo : Matriz Double -> Matriz Double -> List Double -> List Double
residuo h s c = let e = cocienteR h s c in zipWith (\x, y => x - e * y) (matVec h c) (matVec s c)

Idea. Escribimos la acción discreta \(S_h(q_1, \ldots, q_{N-1})\) como una función de la lista de posiciones, y calculamos su gradiente con números duales. En la trayectoria de Verlet, el gradiente es cero a precisión de máquina: Verlet es la condición de extremo de \(S_h\). En la trayectoria exacta, \(\cos t\), no lo es.

Recuerda: \(S_h = \sum_i h\left[\frac12\left(\frac{q_{i+1} - q_i}{h}\right)^2 - V(q_i)\right]\), y \(\frac{\partial S_h}{\partial q_i} = 0\) es la recurrencia de Verlet.

Añade a U5T4.idr:

-- la acción discreta de una trayectoria q_0, …, q_N con paso h: un funcional sobre listas
accionDiscreta : Fractional a => Neg a => a -> (a -> a) -> List a -> a
accionDiscreta h v qs = sum [ h * ((q1 - q0) / h * ((q1 - q0) / h) / 2 - v q0) | (q0, q1) <- zip qs (drop 1 qs) ]

-- ∂S_h/∂q_i para los puntos interiores, con duales: q_i lleva ε, los demás no
gradienteAccion : Double -> (Dual -> Dual) -> List Double -> List Double
gradienteAccion h v qs =
  [ der (accionDiscreta (constante h) v [ MkDual q (if j == i then 1 else 0) | (j, q) <- zip [0 .. length qs] qs ])
  | i <- [1 .. length qs `minus` 2] ]

-- Verlet para el oscilador q'' = −q, desde q_0 = 1, q_1 = cos h, con n pasos
verletOsc : Double -> Nat -> List Double
verletOsc h n = reverse (ir n [cos h, 1])
  where
    ir : Nat -> List Double -> List Double
    ir (S k) (b :: a :: resto) = if k == 0 then b :: a :: resto
                                 else ir k ((2 * b - a - h * h * b) :: b :: a :: resto)
    ir _ qs = qs

accionDiscreta es polimórfica: con Double da el número \(S_h\), y con Dual da además su derivada respecto a la variable que lleve \(\varepsilon\). El gradiente completo se obtiene evaluando la acción una vez por cada punto interior. verletOsc acumula la trayectoria al revés (el valor nuevo se pone al frente, junto a los dos anteriores) y la invierte al final; la lista tiene \(n + 1\) elementos, de \(q_0\) a \(q_n\).

  • En la trayectoria exacta, el gradiente llega a \(8.3\times10^{-5} = \frac{h^3}{12}\): la trayectoria verdadera no es el extremo de \(S_h\). El tamaño es el error local de Verlet, multiplicado por \(h\) por la forma de la acción. Verlet no sigue la dinámica exacta, sino la dinámica exacta de una acción vecina.

La cota, verificada por el compilador

Añade a U5T4.idr:

-- cᵀKc para la matriz tridiagonal K = tridiag(−1, 2, −1), con entradas enteras
formaK : List Integer -> Integer
formaK c = 2 * sum (zipWith (*) c c) - 2 * sum (zipWith (*) c (drop 1 c))

-- ¿cumple c la cota cᵀKc / cᵀc ≥ 2 − √2? Decidido con enteros:
-- con N = cᵀKc y D = cᵀc, es 2D − N ≤ √2·D, es decir, (2D − N ≤ 0) o (2D − N)² ≤ 2D²
cumpleCota : List Integer -> Bool
cumpleCota c =
  let n = formaK c
      d = sum (zipWith (*) c c)
      t = 2 * d - n
  in t <= 0 || t * t <= 2 * d * d

-- So b es el tipo que solo tiene un valor, Oh, cuando b se reduce a True
certificado : So (cumpleCota [5, 7, 5])
certificado = Oh

So (de Data.So) convierte un Bool en un tipo: So True tiene un habitante, Oh, y So False no tiene ninguno. Para aceptar certificado = Oh, Idris tiene que calcular cumpleCota [5, 7, 5] durante la verificación de tipos y comprobar que da True. El vector \((5, 7, 5)\) es una aproximación entera del modo fundamental \((1, \sqrt2, 1)\), y la cota se comprueba sin ningún redondeo, porque todo son enteros.

Predice. Si escribimos el certificado de la proposición contraria, So (not (cumpleCota [5, 7, 5])), ¿lo aceptará Idris?

El paso elemental, demostrado en general

Añade a U5T4.idr:

-- si a ≤ b, entonces w·a ≤ w·b, para todo natural w (por inducción en w)
escalarLTE : (w : Nat) -> {a, b : Nat} -> LTE a b -> LTE (w * a) (w * b)
escalarLTE Z     _ = LTEZero
escalarLTE (S k) p = plusLteMonotone p (escalarLTE k p)

-- un promedio ponderado no baja del menor término: si e0 ≤ e1,
-- entonces (w0 + w1)·e0 ≤ w0·e0 + w1·e1, para pesos naturales cualesquiera
cotaPromedio : (w0, w1 : Nat) -> {e0, e1 : Nat} -> LTE e0 e1 -> LTE ((w0 + w1) * e0) (w0 * e0 + w1 * e1)
cotaPromedio w0 w1 p =
  rewrite multDistributesOverPlusLeft w0 w1 e0 in
    plusLteMonotoneLeft (w0 * e0) (w1 * e0) (w1 * e1) (escalarLTE w1 p)

LTE a b (de Data.Nat) es el tipo de las pruebas de que \(a \leq b\). escalarLTE es una prueba por inducción: para \(w = 0\), \(0 \leq 0\) (LTEZero); para \(w + 1\), \((w+1)a = a + wa\), y basta sumar la hipótesis \(a \leq b\) con la prueba para \(w\) (plusLteMonotone, de la biblioteca). cotaPromedio es la desigualdad del principio variacional con dos niveles: el peso total por la energía menor no supera el promedio ponderado. rewrite aplica la ley distributiva \((w_0 + w_1)e_0 = w_0e_0 + w_1e_0\) para que los tipos coincidan, y el resto es sumar \(w_0e_0\) a los dos lados de \(w_1e_0 \leq w_1e_1\). El compilador comprueba cada paso; si la prueba tuviera un error, el archivo no compilaría.

Predice. Con pesos \(w_0 = 1\), \(w_1 = 2\) y energías \(e_0 = 2 \leq e_1 = 5\), ¿qué afirma cotaPromedio? ¿Hace falta calcular algo para usarla?

U5T4> (3 * 2, 1 * 2 + 2 * 5)
(6, 12)

Lee. El tipo es LTE 6 12: Idris calculó \((1 + 2)\cdot2 = 6\) y \(1\cdot2 + 2\cdot5 = 12\) al verificar el tipo, y el valor es la prueba de \(6 \leq 12\). LTESucc (LTESucc LTEZero) es la prueba de \(2 \leq 5\) (dos pasos de “si \(a \leq b\), entonces \(a + 1 \leq b + 1\)” desde \(0 \leq 3\)). Lo importante es que cotaPromedio vale para todos los pesos y energías naturales: es un teorema, no una comprobación. Para la cota variacional completa faltarían dos piezas grandes: pasar de naturales a reales (o racionales), y la expansión espectral, el teorema de que los vectores propios forman una base. La segunda es la que está fuera del alcance de este curso. Si en el archivo escribiéramos cotaGeneral : (c : List Integer) -> So (cumpleCota c) con cotaGeneral c = ?prueba, Idris aceptaría el enunciado con un hueco pendiente: la proposición está bien formada, y la demostración queda por escribir.

Por qué no sobre Double

Añade a U5T4.idr:

matrizK : Num a => Neg a => Matriz a
matrizK = [[2, -1, 0], [-1, 2, -1], [0, -1, 2]]

-- el cociente de Rayleigh de una matriz, en cualquier tipo fraccionario
cociente : Fractional a => Matriz a -> List a -> a
cociente m c = punto c (matVec m c) / punto c c

-- ¿es r < 2 − √2? Decidido exactamente: r < 2 − √2  ⟺  2 − r > √2  ⟺  (2 − r)² > 2, con 2 − r > 0
bajoLaCota : Racional -> Bool
bajoLaCota r = r < 2 && (2 - r) * (2 - r) > 2

-- un generador congruencial lineal: x ↦ (a x + c) mod 2³¹
lcg : Integer -> Integer
lcg x = (1103515245 * x + 12345) `mod` 2147483648

-- n vectores que difieren del vector propio (1/2, √2/2, 1/2) en perturbaciones de tamaño 10⁻⁹
vectoresCercanos : Nat -> List (List Double)
vectoresCercanos n = ir n 2026
  where
    perturbacion : Integer -> Double
    perturbacion x = 1.0e-9 * (cast x / 1073741824 - 1)
    ir : Nat -> Integer -> List (List Double)
    ir Z     _ = []
    ir (S k) x = let x1 = lcg x
                     x2 = lcg x1
                     x3 = lcg x2
                 in [0.5 + perturbacion x1, sqrt 2 / 2 + perturbacion x2, 0.5 + perturbacion x3] :: ir k x3

aRacional (de Exacto.idr) convierte un Double en el racional exacto que representa, así que comparar aRacional r con la cota no introduce ningún redondeo nuevo. cociente es polimórfico: con Double redondea en cada operación, y con Racional es exacto.

Predice. De 20 000 vectores cercanos al vector propio, ¿cuántos darán un cociente, calculado en Double, por debajo de \(2 - \sqrt2\)? ¿Y si los mismos vectores se convierten a Racional antes de calcular el cociente?

Ejecuta.

U5T4> :exec printLn (length (filter (\c => bajoLaCota (aRacional (cociente matrizK c))) (vectoresCercanos 20000)))
5038
U5T4> :exec printLn (length (filter (\c => bajoLaCota (cociente matrizK (map aRacional c))) (vectoresCercanos 20000)))
0

Lee.

  • En Double, unos 5 000 de los 20 000 cocientes (un 25 %) quedan por debajo de \(\lambda_{\min}\): la proposición “\(\mathcal R \geq \lambda_{\min}\)” es falsa para los números calculados. Un tipo que la exigiera sobre Double no tendría habitantes para esos vectores, aunque el teorema sea verdadero.
  • Con los mismos vectores en Racional, ninguno: la desigualdad exacta se cumple siempre. Por eso el certificado de arriba se escribió con enteros. La proposición que tiene sentido demostrar es sobre números exactos, o con una tolerancia explícita, \(\mathcal R \geq \lambda_{\min} - \epsilon\).

Tu turno. Generaliza cotaPromedio a una lista de pesos y energías, todas mayores o iguales que \(e_0\): el enunciado es “si cada \(e_i \geq e_0\), entonces \((\sum w_i)\,e_0 \leq \sum w_ie_i\)”. Escríbelo como tipo (una forma: recibir la lista de pares y una prueba All de que cada energía cumple LTE e0 e) y demuéstralo por inducción sobre la lista, usando cotaPromedio o escalarLTE en cada paso.
