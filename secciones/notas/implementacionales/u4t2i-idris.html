Idea. La iteración de potencias es un Stream, una sucesión infinita: iterate aplica una y otra vez el mapa \(\mathbf v \mapsto A\mathbf v/\lVert A\mathbf v\rVert\). La consumimos con index en los pasos de la tabla de la nota conceptual, y seguimos el cociente de Rayleigh.

Recuerda: un vector y sus múltiplos son la misma dirección; normalizar es elegir el representante de longitud 1.

Añade a U4T2.idr:

normalizar : Vector -> Vector
normalizar v = escalar (1 / norma v) v

-- la sucesión v, Av/‖Av‖, …: iterar el mapa de un paso en el espacio de direcciones
potencias : Matriz -> Vector -> Stream Vector
potencias a = iterate (normalizar . matVec a)

-- cociente de Rayleigh, para v de longitud 1
rayleigh : Matriz -> Vector -> Double
rayleigh a v = punto v (matVec a v)

normalizar . matVec a es la composición de “multiplicar por \(A\)” y “normalizar”: el mapa de un paso. Como en /u3/t5, un Stream de Idris es infinito y perezoso: potencias a v0 no calcula nada hasta que alguien pide sus elementos, e index k pide el elemento \(k\) (contando desde \(0\)).

Idea. Escribimos la factorización QR con Gram-Schmidt, el paso \(A \mapsto RQ\), y la iteración como otro Stream. Comprobamos el ejemplo de \(2\times2\) y las matrices \(A_1\), \(A_5\) y \(A_{20}\) de \(K\), y que el elemento \((1,1)\) de \(A_k\) es el cociente de Rayleigh de la iteración de potencias.

Recuerda: Gram-Schmidt ortonormaliza las columnas una por una, quitándole a cada una sus componentes en las anteriores.

Añade a U4T2.idr:

-- QR por Gram-Schmidt: A = Q·R
qr : Matriz -> (Matriz, Matriz)
qr a =
  let n = length a
      -- recorre las columnas de A; acumula las columnas de Q y las de R
      (qs, rs) = foldl paso ([], []) (transpose a)
      -- R es triangular superior: la columna j tiene j + 1 coeficientes (en da 0 para los demás)
      coef : Nat -> Nat -> Double
      coef i j = en i (fromMaybe [] (getAt j rs))
  in (transpose qs, [ [ coef i j | j <- [0 .. n `minus` 1] ] | i <- [0 .. n `minus` 1] ])
  where
    paso : (Matriz, Matriz) -> Vector -> (Matriz, Matriz)
    paso (qsAnt, rsAnt) aj =
      let rj  = [ punto qi aj | qi <- qsAnt ]                                   -- componentes en las anteriores
          v   = foldl (zipWith (-)) aj [ escalar r qi | (r, qi) <- zip rj qsAnt ]  -- se las quitamos
          rjj = norma v
      in (qsAnt ++ [escalar (1 / rjj) v], rsAnt ++ [rj ++ [rjj]])

-- un paso del algoritmo: factorizar A = QR y multiplicar al revés
pasoQR : Matriz -> Matriz
pasoQR a = let (q, r) = qr a in matMul r q

iteracionQR : Matriz -> Stream Matriz
iteracionQR = iterate pasoQR

qr trabaja con las columnas de \(A\), que son las filas de su transpuesta. Para cada columna \(\mathbf a_j\), calcula sus componentes \(r_{ij} = \mathbf q_i\cdot\mathbf a_j\) sobre las columnas ya ortonormalizadas, se las resta, y normaliza lo que queda.

Tu turno. Mide la razón con que decae el elemento \((2,3)\) de \(A_k\) (en Idris, elemento 1 2) entre dos pasos consecutivos, para \(k\) grande. ¿Es \(\lambda_3/\lambda_2 = 0.586/2 = 0.293\)?

Idea. Construimos la reflexión \(H = I - 2\mathbf u\mathbf u^T/\lVert\mathbf u\rVert^2\), el espejo que lleva un vector \(\mathbf x\) al primer eje, y con él una función recursiva que tridiagonaliza cualquier matriz simétrica. Comprobamos que conserva los valores propios.

Recuerda: con \(\mathbf u = \mathbf x + \lVert\mathbf x\rVert\,\mathbf e_1\), la reflexión lleva \(\mathbf x\) a \(-\lVert\mathbf x\rVert\,\mathbf e_1\).

Añade a U4T2.idr:

-- H = I − 2uuᵀ/‖u‖²
reflexion : Vector -> Matriz
reflexion u =
  let uu = punto u u
  in [ [ d - 2 * ui * uj / uu | (uj, d) <- zip u fila ] | (ui, fila) <- zip u (identidad (length u)) ]

-- el espejo que lleva x al primer eje
espejoPara : Vector -> Matriz
espejoPara x = reflexion (zipWith (+) x (norma x :: replicate (length x) 0))

-- la matriz por bloques (1, H): no toca la primera fila ni la primera columna
bloque : Matriz -> Matriz
bloque h = (1 :: map (const 0) h) :: [ 0 :: fila | fila <- h ]

-- tridiagonalización: una reflexión para la primera columna, y recursión sobre el bloque restante
tridiagonalizar : Matriz -> Matriz
tridiagonalizar a = tri (length a) a
  where
    tri : Nat -> Matriz -> Matriz
    tri Z     m = m
    tri (S c) m =
      if length m <= 2 then m
      else let x = drop 1 (fromMaybe [] (head' (transpose m)))     -- la primera columna, bajo la diagonal
               h = bloque (espejoPara x)
           in case matMul h (matMul m h) of                         -- HAH
                (fila1 :: resto) => fila1 :: zipWith (::) (map (en 0) resto) (tri c (map (drop 1) resto))
                [] => []

zipWith (+) x (norma x :: replicate (length x) 0) suma \(\lVert\mathbf x\rVert\) solo a la primera componente: es \(\mathbf x + \lVert\mathbf x\rVert\,\mathbf e_1\). Después de la primera reflexión, la primera fila y la primera columna ya son tridiagonales, y el resto es un problema del mismo tipo con una dimensión menos: la recursión lo resuelve, y las reflexiones siguientes no tocan lo ya hecho. La matriz se encoge en cada llamada, pero Idris no lo ve en map (drop 1) resto; el contador c, que empieza en el tamaño de la matriz, es el combustible que garantiza que tri termina.

Idea. La sucesión de Sturm se genera con una recurrencia de tres términos, como la de Fibonacci: cada término nuevo usa los dos anteriores. La escribimos para cualquier tipo numérico, así que la tabla de la nota conceptual sale exacta en Racional. Contamos sus cambios de signo y, con la bisección de /u2/t6, localizamos cualquier valor propio por su número.

Recuerda: \(p_0 = 1\), \(p_1 = a_1 - \lambda\), \(p_k = (a_k - \lambda)\,p_{k-1} - b_{k-1}^2\,p_{k-2}\), y el número de cambios de signo es el número de valores propios menores que \(\lambda\).

Añade a U4T2.idr:

-- una tridiagonal simétrica: (diagonal, elementos fuera de la diagonal)
Tridiagonal : Type -> Type
Tridiagonal a = (List a, List a)

-- p₀, p₁, …, pₙ
sturm : Num a => Neg a => Tridiagonal a -> a -> List a
sturm ([], _) lam = [1]
sturm (d1 :: ds, e) lam = 1 :: ir 1 (d1 - lam) ds e
  where
    -- p2 y p1 son los dos términos anteriores
    ir : a -> a -> List a -> List a -> List a
    ir p2 p1 (dk :: ds') (ek :: es) = p1 :: ir p1 ((dk - lam) * p1 - ek * ek * p2) ds' es
    ir _  p1 _ _ = [p1]

-- cambios de signo; un cero toma el signo contrario al del término anterior
cambios : Num a => Ord a => List a -> Nat
cambios [] = 0
cambios (p :: ps) = ir (signo p) ps
  where
    signo : a -> Integer
    signo x = if x > 0 then 1 else if x < 0 then -1 else 0
    ir : Integer -> List a -> Nat
    ir _ [] = 0
    ir anterior (q :: qs) =
      let s = if q == 0 then negate anterior else signo q
      in (if s /= anterior then 1 else 0) + ir s qs

-- el valor propio número j, por bisección en [a, b] (60 mitades)
valorPropio : Nat -> Tridiagonal Double -> Double -> Double -> Double
valorPropio j t a b = ir 60 a b
  where
    ir : Nat -> Double -> Double -> Double
    ir Z     x y = (x + y) / 2
    ir (S k) x y = let m = (x + y) / 2
                   in if cambios (sturm t m) >= j then ir k x m    -- hay al menos j valores propios < m
                                                  else ir k m y

ir lleva los dos términos anteriores, p2 y p1, como acumuladores: es la forma estricta de la recurrencia, y cada llamada consume un elemento de la diagonal y uno de fuera de ella, así que Idris acepta que termina. La regla para los ceros de cambios resuelve el caso en que algún \(p_k\) es exactamente \(0\).

Predice. Para \(K\) (diagonal \(2\), fuera de la diagonal \(-1\)), ¿cuántos cambios de signo hay en \(\lambda = \frac12,\ \frac32,\ \frac52,\ \frac72\)? ¿Qué valores propios dará la bisección?

Lee.

  • Es la tabla de la nota conceptual, en fracciones exactas: \(0, 1, 2, 3\) cambios, uno más cada vez que \(\lambda\) cruza un valor propio. Idris escribe una terna (a, b, c) como (a, (b, c)): es un par cuyo segundo elemento es otro par.
  • La bisección da \(0.5857864376269049 = 2 - \sqrt2\), \(2\) y \(3.414213562373095 = 2 + \sqrt2\), en todas las cifras, y cada uno se pidió por su número, sin calcular los demás.
  • Exactamente en \(\lambda = 2\), un valor propio, \(p_3 = 0\) (sin redondeo: en \(\mathbb{Q}\) el cero es un cero de verdad), y la regla de los ceros cuenta \(2\): incluye al propio \(\lambda = 2\). En la bisección no importa, porque el punto medio casi nunca cae exactamente en un valor propio.

Idea. Construimos la matriz de la cuerda discretizada, pedimos su primer valor propio con Sturm y bisección para \(n = 3, 7, 15, 31\), y comparamos con \(\pi^2\). Después resolvemos el problema generalizado \(K\mathbf v = \omega^2M\mathbf v\) con una masa central más pesada, reduciéndolo con Cholesky a uno ordinario.

Recuerda: con \(M = LL^T\), el problema \(K\mathbf v = \omega^2M\mathbf v\) equivale a \((L^{-1}KL^{-T})\,\mathbf w = \omega^2\mathbf w\); si \(M\) es diagonal, \(L\) es la diagonal de las raíces de las masas.

Añade a U4T2.idr:

-- la cuerda con c = L = 1 y n puntos interiores: la tridiagonal K/h²
cuerda : Nat -> Tridiagonal Double
cuerda n =
  let h = 1 / cast (n + 1)
  in (replicate n (2 / (h * h)), replicate (n `minus` 1) (-1 / (h * h)))

-- L⁻¹ K L⁻ᵀ con M = diag(ms): cada elemento entre la raíz de las dos masas
reducirConMasas : Vector -> Matriz -> Matriz
reducirConMasas ms k = [ [ kij / sqrt (mi * mj) | (kij, mj) <- zip fila ms ] | (fila, mi) <- zip k ms ]

Predice. La nota conceptual da \(\lambda_1 = 9.3726,\ 9.7434,\ 9.8379,\ 9.8617\), con errores que se dividen entre 4. Para el modo más alto con \(n = 31\), ¿qué tan lejos estará de \((31\pi)^2\)? Con la masa central doble, ¿qué frecuencias al cuadrado saldrán?

Lee.

  • Los \(\lambda_1\) son los de la tabla de la nota conceptual, y los errores, \(0.497,\ 0.126,\ 0.032,\ 0.008\), se dividen entre 4: orden 2.
  • El modo más alto con \(n = 31\) da \(4086\) frente a \(9485\): apenas el \(43\,\%\). Con 2 puntos por longitud de onda, la malla no representa ese modo.
  • La matriz reducida es simétrica, con \(-0.7071 = -1/\sqrt2\) fuera de la diagonal y \(1 = 2/2\) en el centro. Sus valores propios son \(2.618 = \frac{3+\sqrt5}2\), \(2\) y \(0.382 = \frac{3-\sqrt5}2\): el modo central conserva \(\omega^2 = 2\), y los otros dos bajan, como en la nota conceptual.
