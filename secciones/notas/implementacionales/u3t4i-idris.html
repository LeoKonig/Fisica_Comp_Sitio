Cómo leer esta nota. Cada pestaña corresponde a una pestaña de la nota conceptual y sigue el esquema Idea → Predice → Ejecuta → Lee → Tu turno. Todas las salidas se obtuvieron con Idris2 0.7.0.

Las definiciones (bloques sin prompt) van en un archivo U3T4.idr. Las consultas (con el prompt U3T4>) se escriben en el REPL, sin el prompt. Abre el REPL con idris2 U3T4.idr y usa :r para recargar el archivo cuando añadas algo. Esta nota no necesita Exacto.idr.

Los integradores, con números complejos. La ecuación de prueba \(\dot y = \lambda y\) tiene \(\lambda\) complejo, así que el estado \(y\) también lo es. Retomamos el tipo Complejo de /u3/t2 y la interfaz Vec de /u3/t1. Basta decirle a Idris que los complejos se suman y se multiplican por un real: los mismos Euler, Heun y RK4 funcionarán con ellos sin cambiar una línea.

Archivo U3T4.idr:

module U3T4

import Data.List
import Data.String

%default total

infixl 6 ^+^
infixl 7 *^

-- ── números complejos a + b i (ver /u3/t2) ──
record Complejo where
  constructor MkC
  re : Double
  im : Double

Num Complejo where
  MkC a b + MkC c d = MkC (a + c) (b + d)
  MkC a b * MkC c d = MkC (a * c - b * d) (a * d + b * c)
  fromInteger n = MkC (fromInteger n) 0

Neg Complejo where
  negate (MkC a b) = MkC (negate a) (negate b)
  MkC a b - MkC c d = MkC (a - c) (b - d)

Fractional Complejo where
  MkC a b / MkC c d = let m = c * c + d * d in MkC ((a * c + b * d) / m) ((b * c - a * d) / m)

-- un literal decimal, como 0.5, también puede ser un complejo (con parte imaginaria 0)
FromDouble Complejo where
  fromDouble x = MkC x 0

-- |a + b i|, escalado para no elevar al cuadrado números diminutos
modulo : Complejo -> Double
modulo (MkC a b) =
  let m = max (abs a) (abs b)
  in if m == 0 then 0 else m * sqrt ((a / m) * (a / m) + (b / m) * (b / m))

real : Double -> Complejo
real x = MkC x 0

-- ── estados como vectores (ver /u3/t1) ──
interface Vec v where
  (^+^) : v -> v -> v
  (*^)  : Double -> v -> v

Vec Double where
  (^+^) = (+)
  (*^)  = (*)

-- un complejo es un vector: k·z = (k + 0i)·z
Vec Complejo where
  (^+^)  = (+)
  k *^ z = MkC k 0 * z

(Vec a, Vec b) => Vec (a, b) where
  (x, y) ^+^ (z, w) = (x ^+^ z, y ^+^ w)
  k *^ (x, y)       = (k *^ x, k *^ y)

Campo : Type -> Type
Campo v = v -> v

euler : Vec v => Double -> Campo v -> v -> v
euler h f y = y ^+^ h *^ f y

heun : Vec v => Double -> Campo v -> v -> v
heun h f y =
  let k1 = f y
      k2 = f (y ^+^ h *^ k1)
  in y ^+^ (h / 2) *^ (k1 ^+^ k2)

rk4 : Vec v => Double -> Campo v -> v -> v
rk4 h f y =
  let k1 = f y
      k2 = f (y ^+^ (h / 2) *^ k1)
      k3 = f (y ^+^ (h / 2) *^ k2)
      k4 = f (y ^+^ h *^ k3)
  in y ^+^ (h / 6) *^ (k1 ^+^ 2 *^ k2 ^+^ 2 *^ k3 ^+^ k4)

final : Nat -> (a -> a) -> a -> a
final Z     paso x = x
final (S n) paso x = final n paso (paso x)

El REPL muestra un complejo como MkC a b, que es \(a + bi\); MkC 0 1 es \(i\). Gracias a FromDouble, un literal como 0.5 o -1.0e6 se puede usar directamente donde se espera un Complejo.

  • La ecuación de prueba de Dahlquist
  • A, A(α), L: tres grados de estabilidad
  • El eje imaginario: Euler diverge, RK4 tolera
  • EDOs rígidas: múltiples escalas temporales

Idea. Un paso de cualquier método sobre \(\dot y = \lambda y\) multiplica \(y\) por \(R(h\lambda)\). Con \(h = 1\), \(\lambda = z\) y \(y = 1\), un paso devuelve exactamente \(R(z)\). Así, la función de estabilidad de un método explícito no hay que deducirla: se obtiene ejecutándolo.

Añade a U3T4.idr:

-- un integrador, para la ecuación de prueba con estado complejo
Metodo : Type
Metodo = Double -> Campo Complejo -> Complejo -> Complejo

-- R(z) = resultado de un paso con h = 1, f(y) = z·y, desde y = 1
funcionR : Metodo -> Complejo -> Complejo
funcionR metodo z = metodo 1 (\y => z * y) 1

-- los implícitos, despejados a mano
rEulerImplicito : Complejo -> Complejo
rEulerImplicito z = 1 / (1 - z)

rTrapecio : Complejo -> Complejo
rTrapecio z = (1 + z / 2) / (1 - z / 2)

-- x en notación científica con tres decimales, p. ej. "-1.500e0"
cientifica : Double -> String
cientifica x =
  if x == 0 then "0.000e0"
  else if x < 0 then "-" ++ positivo (negate x) else positivo x
  where
    positivo : Double -> String
    positivo y =
      let e0 = floor (log y / log 10)                                   -- exponente decimal
          c0 = the Integer (cast (floor (y / pow 10 e0 * 1000 + 0.5)))  -- mantisa × 1000
          (c, e) = if c0 >= 10000 then (c0 `div` 10, e0 + 1) else (c0, e0)
      in show (c `div` 1000) ++ "." ++ padLeft 3 '0' (show (c `mod` 1000)) ++ "e" ++ show (the Integer (cast e))

columna : Nat -> String -> String
columna n s = padLeft n ' ' s

-- R(z) sobre el eje real, para los cinco métodos
tablaReal : List Double -> IO ()
tablaReal zs = do
  putStrLn (columna 7 "z" ++ concat (map (columna 11) ["exp z", "Euler", "Heun", "RK4", "E. impl.", "Trapecio"]))
  for_ zs $ \x =>
    putStrLn (columna 7 (show x) ++ concat (map (columna 11 . cientifica)
      [exp x, re (funcionR euler (real x)), re (funcionR heun (real x)), re (funcionR rk4 (real x)),
       re (rEulerImplicito (real x)), re (rTrapecio (real x))]))

-- bisección, como en /u2/t6 (60 mitades)
biseccion : (Double -> Double) -> Double -> Double -> Double
biseccion g a b = ir 60 a b
  where
    ir : Nat -> Double -> Double -> Double
    ir Z     x y = (x + y) / 2
    ir (S k) x y = let m = (x + y) / 2
                   in if (g m < 0) == (g x < 0) then ir k m y else ir k x m

funcionR euler es una función Complejo -> Complejo: la \(R\) de Euler, obtenida sin escribir \(1 + z\) en ningún lado. cientifica y tablaReal solo dan formato, como en /u2/t2; tablaReal devuelve IO (), una acción que imprime, y se ejecuta con :exec.

Predice. ¿Qué debería dar funcionR euler en \(z = 0.5\)? ¿Y funcionR rk4 en \(z = i\), comparado con \(1 + z + \frac{z^2}2 + \frac{z^3}6 + \frac{z^4}{24}\)?

Lee.

  • \(R_{\text{Euler}}(0.5) = 1.5\), y \(R_{\text{RK4}}(i) = 1 + i - \frac12 - \frac i6 + \frac1{24} = \frac{13}{24} + \frac56 i\): el polinomio de Taylor de \(e^i\), obtenido ejecutando RK4 una vez.
  • Es la tabla de la nota conceptual. Para \(|z|\) pequeño todos aproximan bien a \(e^z\); para \(|z|\) grande, los tres explícitos explotan (\(-999\), \(5\times10^5\), \(4\times10^{10}\)) y los dos implícitos no.
  • La bisección encuentra el extremo izquierdo del intervalo real de estabilidad de RK4: \(-2.785\). El de Euler y Heun es \(-2\).

La región de estabilidad, dibujada

Añade a U3T4.idr:

-- el carácter del punto z = i/10 + (j/5)·i: '#' si |R(z)| ≤ 1; '|' y '-' son los ejes
simbolo : (Complejo -> Complejo) -> Integer -> Integer -> Char
simbolo r i j =
  let x = cast i / 10
      y = cast j / 5
  in if modulo (r (MkC x y)) <= 1 then '#'
     else if i == 0 && j == 0 then '+'
     else if i == 0 then '|'
     else if j == 0 then '-'
     else '.'

-- mapa del plano complejo: x de −4 a 1 (paso 0.1), y de 3.4 a −3.4 (paso 0.2)
region : (Complejo -> Complejo) -> IO ()
region r = for_ [17, 16 .. -17] $ \j =>
  putStrLn (pack [ simbolo r i j | i <- [-40 .. 10] ])

Cada carácter es un punto \(z\) del plano complejo; el paso vertical es el doble del horizontal porque los caracteres son más altos que anchos. Las coordenadas se recorren con enteros i y j y se dividen al final: así los ejes caen exactamente en i == 0 y j == 0. pack convierte la lista de caracteres en un String.

Añade a U3T4.idr:

-- los puntos (i/2) + (j/2)·i, con i de i0 a i1 y j de −100 a 100
rejilla : Integer -> Integer -> List Complejo
rejilla i0 i1 = [ MkC (cast i / 2) (cast j / 2) | i <- [i0 .. i1], j <- [-100 .. 100] ]

rejilla (-100) (-1) cubre el semiplano izquierdo abierto (\(-50 \le x \le -0.5\), \(|y| \le 50\), unos \(20\,000\) puntos); rejilla 0 0 es el eje imaginario, y rejilla 1 100, el semiplano derecho.

Predice. ¿Cumple el trapecio \(|R(z)| \le 1\) en todo el semiplano izquierdo? ¿Y en el derecho? En el eje imaginario la teoría da \(|R(iy)| = 1\) exactamente: ¿qué dará Double? ¿Cuánto valen \(R(-100)\) y \(R(-10^6)\) para cada implícito?

Lee.

  • En el semiplano izquierdo, el trapecio cumple \(|R| \le 1\) en todos los puntos (all da True), y en el semiplano derecho, en ninguno (any da False). Su región de estabilidad es exactamente el semiplano izquierdo: es A-estable. (Puedes verlo también con region rTrapecio.)
  • En el eje imaginario, la frontera, \(|R(iy)|\) sale \(1\) con una diferencia de a lo más \(2.2\times10^{-16}\): un ulp de \(1\) (/u1/t1). Por eso la prueba del semiplano izquierdo deja fuera el eje: en algunos de sus puntos el redondeo da \(1 + 2.2\times10^{-16} > 1\), y <= 1 fallaría por una razón que no tiene nada que ver con la estabilidad.
  • Con \(z = -100\), Euler implícito reduce el modo 100 veces en un paso; el trapecio lo deja en \(-0.961\): cambia de signo y conserva el 96 % de su amplitud.
  • Con \(z = -10^6\), Euler implícito da \(10^{-6} \to 0\), y el trapecio \(-0.999996 \to -1\). Son \(R(\infty) = 0\) (L-estable) y \(R(\infty) = -1\) (no L-estable).

-- (|R(iy)| por paso, amplitud tras 100 pasos) para RK4
amplitudRK4 : Double -> (Double, Double)
amplitudRK4 y = let m = modulo (funcionR rk4 (MkC 0 y)) in (m, pow m 100)

Verlet sobre el eje imaginario

La nota conceptual explica que un método simpléctico no puede disipar: los valores propios de su matriz vienen en parejas \(\mu\) y \(1/\mu\), así que o todos tienen módulo \(1\) o alguno es mayor que \(1\). Lo comprobamos con el paso de Verlet en el oscilador \(\ddot q = -\omega^2 q\), que es la matriz de /u3/t1 con \(h\) cambiado por \(y = h\omega\). Añade a U3T4.idr:

-- ((a, b), (c, d)) = filas de una matriz 2×2
M22 : Type
M22 = ((Double, Double), (Double, Double))

-- el paso de Verlet en el oscilador de frecuencia ω, con y = hω
matrizVerlet : Double -> M22
matrizVerlet y = ((1 - y * y / 2, y), (- y * (1 - y * y / 4), 1 - y * y / 2))

-- raíz cuadrada de un real, como complejo: imaginaria pura si x < 0
raizC : Double -> Complejo
raizC x = if x >= 0 then MkC (sqrt x) 0 else MkC 0 (sqrt (negate x))

-- valores propios de una matriz 2×2: raíces de μ² − (traza) μ + det = 0
valoresPropios : M22 -> (Complejo, Complejo)
valoresPropios ((a, b), (c, d)) =
  let tr = a + d
      s  = raizC (tr * tr - 4 * (a * d - b * c))
  in ((real tr + s) / 2, (real tr - s) / 2)

-- el ángulo de un complejo, en (−π, π]
argumento : Complejo -> Double
argumento (MkC a b) =
  if a > 0 then atan (b / a)
  else if a < 0 then (if b >= 0 then atan (b / a) + pi else atan (b / a) - pi)
  else (if b >= 0 then pi / 2 else - pi / 2)

Idris no tiene atan2, así que argumento elige el cuadrante a mano: atan (b / a) solo da ángulos entre \(-\frac\pi2\) y \(\frac\pi2\).

Predice. Con \(h\omega = 0.1\), \(1\) y \(1.9\), ¿qué módulo tendrán los valores propios de Verlet? ¿Y con \(h\omega = 2.5\)? Compara con el \(|R(i)| = 0.9939\) de RK4.

Ejecuta.

U3T4> [ (y, modulo (fst (valoresPropios (matrizVerlet y))), modulo (snd (valoresPropios (matrizVerlet y)))) | y <- [0.1, 1, 1.9, 2.5] ]
[(0.1, (0.9999999999999999, 0.9999999999999999)), (1.0, (1.0, 1.0)), (1.9, (1.0, 1.0)), (2.5, (0.25, 4.0))]
U3T4> [ (y, argumento (fst (valoresPropios (matrizVerlet y))), argumento (fst (valoresPropios (matrizVerlet y))) / y) | y <- [0.1, 1, 1.9] ]
[(0.1, (0.10004171361153981, 1.000417136115398)), (1.0, (1.0471975511965976, 1.0471975511965976)), (1.9, (2.50647179500675, 1.3191956815825001))]

Lee.

  • Para \(h\omega = 0.1\), \(1\) y \(1.9\), los dos valores propios tienen módulo \(1\): Verlet ni amortigua ni amplifica, a diferencia de RK4, que con \(h\omega = 1\) perdía la mitad de la amplitud en 100 pasos.
  • Con \(h\omega = 2.5 > 2\), los valores propios son reales (negativos), de módulos \(0.25\) y \(4\) y producto \(1\): uno de ellos hace explotar el método. No hay término medio, como predice la pareja \(\mu\), \(1/\mu\).
  • El ángulo por paso es \(\theta\) en lugar de \(h\omega\); la razón \(\theta/(h\omega)\) es \(1.00042\), \(1.047\) y \(1.32\). El error de Verlet está en la fase, el “reloj” de la oscilación, y no en la energía.

Tu turno. Un sistema tiene frecuencias \(\omega = 1\) y \(\omega = 100\). ¿Cuál es el mayor \(h\) con el que RK4 es estable? Compruébalo con amplitudRK4 aplicado a \(h \cdot 100\).

Idea. El sistema 2×2 de la nota conceptual tiene modos con \(\lambda = -1\) y \(\lambda = -1000\). Euler explícito trabaja con pares gracias a Vec; los dos implícitos necesitan, en cada paso, resolver un sistema lineal 2×2.

Recuerda: cada modo se multiplica por \(R(h\lambda_i)\), y el más exigente decide la estabilidad.

Añade a U3T4.idr:

V2 : Type
V2 = (Double, Double)

-- (M22, las matrices 2×2 por filas, se definió en la pestaña del eje imaginario)

-- A · y
aplicar : M22 -> V2 -> V2
aplicar ((a, b), (c, d)) (x, y) = (a * x + b * y, c * x + d * y)

-- resuelve M · x = v por la regla de Cramer
resolver2 : M22 -> V2 -> V2
resolver2 ((a, b), (c, d)) (e, f) =
  let det = a * d - b * c
  in ((e * d - b * f) / det, (a * f - e * c) / det)

-- I − k·M
menos : Double -> M22 -> M22
menos k ((a, b), (c, d)) = ((1 - k * a, - k * b), (- k * c, 1 - k * d))

matA : M22
matA = ((-500.5, 499.5), (499.5, -500.5))

-- solución exacta desde (2, 0)
exacto2 : Double -> V2
exacto2 t = (exp (- t) + exp (-1000 * t), exp (- t) - exp (-1000 * t))

-- (I − hA) y' = y                  (Euler implícito)
eulerImpl2 : Double -> V2 -> V2
eulerImpl2 h y = resolver2 (menos h matA) y

-- (I − h/2 A) y' = y + h/2 A y     (trapecio)
trapecio2 : Double -> V2 -> V2
trapecio2 h y = resolver2 (menos (h / 2) matA) (y ^+^ (h / 2) *^ aplicar matA y)

Como el sistema es lineal, cada paso implícito es un sistema lineal: no hace falta Newton. aplicar matA es un Campo V2, así que euler h (aplicar matA) es el Euler explícito de siempre.

Predice. Euler explícito necesita \(h \le 0.002\). ¿Qué resultados dará con \(h = 0.0025\), \(0.0021\) y \(0.0019\) en \(t \approx 1\)? Con \(h = 0.1\), ¿qué harán los dos implícitos con el modo rápido?

  • Euler implícito, con \(h = 0.1\): desde el paso 2 las dos componentes casi coinciden, como en la solución exacta. El modo rápido se redujo 100 veces en un solo paso.
  • Trapecio: las componentes saltan entre valores como \((-0.06,\ 1.87)\) y \((1.74,\ -0.10)\). El modo rápido sobrevive con signo alternante, \((-0.961)^n\), y en el paso 10 todavía pesa \(0.67\).
