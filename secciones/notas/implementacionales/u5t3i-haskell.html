Un solo método para todos los valores propios. Esta nota calcula valores propios de matrices de diferencias finitas (tridiagonales), de bases de Galerkin (pequeñas y densas, con traslape \(\mathbf S\)) y del oscilador anarmónico (con banda). En lugar de escribir un método para cada caso, generalizamos la secuencia de Sturm de /u4/t2: para contar cuántos valores propios de \(\mathbf H\vec c = E\,\mathbf S\vec c\) son menores que \(\lambda\), basta hacer la eliminación gaussiana de /u4/t1 sin pivoteo sobre \(\mathbf H - \lambda\mathbf S\) y contar los pivotes negativos. Con esa cuenta, la bisección encuentra cada valor propio por su número. Como todo es polimórfico, la misma cuenta funciona con Rational, y entonces es una prueba exacta.

Recuerda: la ley de inercia de Sylvester dice que si \(A = LDL^T\) con \(L\) invertible, \(A\) y \(D\) tienen el mismo número de valores propios negativos. La eliminación sin pivoteo de una matriz simétrica da exactamente \(A = LDL^T\), con los pivotes en la diagonal de \(D\). Si \(\mathbf S = GG^T\) (Cholesky), \(\mathbf H - \lambda\mathbf S = G\,(\tilde{\mathbf H} - \lambda I)\,G^T\), y los valores propios de \(\tilde{\mathbf H} - \lambda I\) son \(E_k - \lambda\): los pivotes negativos cuentan los \(E_k < \lambda\). Para una tridiagonal, los pivotes son los cocientes \(p_k/p_{k-1}\) de la secuencia de Sturm, y contar pivotes negativos es contar cambios de signo.

Archivo U5T3.hs:

import Data.Ratio
import Data.List (transpose)

type Matriz a = [[a]]          -- lista de filas

identidad :: Num a => Int -> Matriz a
identidad n = [ [ if i == j then 1 else 0 | j <- [1 .. n] ] | i <- [1 .. n] ]

matMul :: Num a => Matriz a -> Matriz a -> Matriz a
matMul a b = [ [ sum (zipWith (*) fila col) | col <- transpose b ] | fila <- a ]

-- los pivotes de la eliminación gaussiana sin pivoteo (ver /u4/t1)
pivotes :: (Eq a, Fractional a) => Matriz a -> [a]
pivotes [] = []
pivotes ((p : fila) : resto) = p : pivotes (map reducir resto)
  where
    reducir (c : xs)
      | c == 0    = xs                                     -- nada que anular: ahorra trabajo
      | otherwise = zipWith (\x y -> x - c / p * y) xs fila

-- cuántos valores propios de H c = E S c son menores que λ: los pivotes negativos de H − λS
contarMenores :: (Ord a, Fractional a) => Matriz a -> Matriz a -> a -> Int
contarMenores h s lam = length (filter (< 0) (pivotes (zipWith (zipWith (\x y -> x - lam * y)) h s)))

-- el valor propio número k (desde 1), por bisección en [a, b] con el número de pasos dado
valorPropio :: (Ord a, Fractional a) => Int -> Matriz a -> Matriz a -> (a, a) -> Int -> a
valorPropio k h s (a0, b0) pasos = ir pasos a0 b0
  where
    ir 0 a b = (a + b) / 2
    ir n a b
      | contarMenores h s m >= k = ir (n - 1) a m          -- hay al menos k valores propios < m
      | otherwise                = ir (n - 1) m b
      where
        m = (a + b) / 2

-- la matriz tridiagonal con d en la diagonal y e fuera de ella
tridiag :: Num a => a -> a -> Int -> Matriz a
tridiag d e n = [ [ if i == j then d else if abs (i - j) == 1 then e else 0 | j <- [1 .. n] ] | i <- [1 .. n] ]

En pivotes, cada paso usa el primer elemento p de la primera fila y resta a las demás filas el múltiplo que anula su primer elemento, como en /u4/t1; los pivotes son los p sucesivos. Las filas cuyo primer elemento ya es cero no se tocan, de modo que una matriz tridiagonal cuesta solo una fila por paso. Si algún pivote fuera exactamente cero, λ coincidiría con un valor propio de un bloque; con Double es improbable, y con Rational produce un error de división entre cero que obliga a elegir otro λ.

  • El hamiltoniano matricial como suma de operadores
  • La proyección de Galerkin preserva la estructura hermítica
  • Teorema de MacDonald–Hylleraas–Undheim: cotas superiores garantizadas, solo para Ritz

Idea. Construimos la matriz de diferencias finitas como cinético más potencial, y comprobamos que los niveles del pozo y del oscilador quedan por debajo de los exactos y suben al refinar, con orden \(O(h^2)\).

Recuerda: \(H_{ij} = \frac{1}{2h^2}(2\delta_{ij} - \delta_{i,j+1} - \delta_{i,j-1}) + V(x_i)\,\delta_{ij}\), en los \(n\) puntos interiores de \([a, b]\), con \(h = \frac{b - a}{n + 1}\).

Añade a U5T3.hs:

-- el hamiltoniano de diferencias finitas en n puntos interiores de [a, b]
hamiltonianoDF :: (Double -> Double) -> (Double, Double) -> Int -> Matriz Double
hamiltonianoDF v (a, b) n = zipWith3 fila [0 ..] xs cinetico
  where
    h        = (b - a) / fromIntegral (n + 1)
    xs       = [ a + h * fromIntegral i | i <- [1 .. n] ]
    cinetico = tridiag (1 / (h * h)) (-1 / (2 * h * h)) n      -- (1/2h²)·tridiag(−1, 2, −1)
    fila i x f = [ if j == i then c + v x else c | (j, c) <- zip [0 :: Int ..] f ]   -- + V(x_i) en la diagonal

-- todos los valores propios de H c = E S c, de menor a mayor
espectro :: Matriz Double -> Matriz Double -> [Double]
espectro h s = [ valorPropio k h s (0, cota) 60 | k <- [1 .. length h] ]
  where
    cota = 2 * maximum [ sum (map abs f) | f <- h ] / minimum [ f !! i | (i, f) <- zip [0 ..] s ]

hamiltonianoDF es literalmente la suma de la nota conceptual: la parte cinética cinetico, y \(V(x_i)\) sumado en la diagonal. cota es una cota superior de todos los valores propios (la mayor suma de valores absolutos de una fila, que acota los valores propios de \(\mathbf H\), dividida entre el menor elemento diagonal de \(\mathbf S\), con un factor 2 de holgura); los potenciales de esta nota son no negativos, así que todos los valores propios están en \([0, \text{cota}]\).

Predice. Para el pozo \([0, 1]\) con \(n = 3\), la matriz debe ser \(8K\), con valores propios \(8\times(0.586,\ 2,\ 3.414)\). ¿Quedan por encima o por debajo de los exactos \(\frac{k^2\pi^2}{2} = 4.935,\ 19.74,\ 44.41\)?

Lee.

  • La matriz es \(8K\), y sus valores propios son \(4.686,\ 16,\ 27.314\): los de la nota conceptual, los tres por debajo de los exactos.
  • \(E_1\) sube \(4.686,\ 4.872,\ 4.919,\ 4.931\) hacia \(4.935\), y el error se divide entre 4 en cada fila: \(O(h^2)\), siempre desde abajo.
  • En el oscilador sobre \([-8, 8]\), con \(h = 0.5,\ 0.25,\ 0.125\) (\(n = 31, 63, 127\)), \(E_0 = 0.49206,\ 0.49804,\ 0.49951\): también por debajo de \(0.5\).

Tu turno. Construye hamiltonianoDF para el pozo con \(n = 3\) y comprueba con contarMenores que hay exactamente un valor propio menor que \(5\) y dos menores que \(17\). ¿Qué dice eso de usar \(4.686\) como “cota superior”?

Idea. Calculamos en \(\mathbb{Q}\) las matrices de los dos polinomios de la nota conceptual, sus valores propios generalizados, y una cuenta exacta que encierra al valor de Ritz entre dos racionales. Reducimos con Löwdin, y medimos el defecto de composición con el operador posición truncado.

Recuerda: \(S_{ij} = \int_0^1\phi_i\phi_j\) y \(H_{ij} = \frac12\int_0^1\phi'_i\phi'_j\), con \(\phi_1 = x(1 - x)\), \(\phi_2 = x^2(1 - x)^2\), y todas las integrales salen de \(\int_0^1x^a(1 - x)^a\,dx = \frac{(a!)^2}{(2a+1)!}\).

Añade a U5T3.hs:

-- ∫₀¹ x^a (1−x)^a dx = (a!)² / (2a+1)!, exacta
beta :: Integer -> Rational
beta a = fromIntegral (product [1 .. a]) ^ 2 / fromIntegral (product [1 .. 2 * a + 1])

-- las matrices de Galerkin de los dos polinomios (la nota conceptual las deduce a mano)
hPol, sPol :: Matriz Rational
hPol = [[1 % 6, 1 % 30], [1 % 30, 1 % 105]]
sPol = [[beta 2, beta 3], [beta 3, beta 4]]

aDouble :: Matriz Rational -> Matriz Double
aDouble = map (map fromRational)

-- valores y vectores propios (unitarios) de una matriz simétrica de 2×2
propios2 :: Matriz Double -> [(Double, [Double])]
propios2 [[a, b], [_, d]] = [ (l, unitario [b, l - a]) | l <- [m - r, m + r] ]
  where
    m = (a + d) / 2
    r = sqrt (((a - d) / 2) ^ 2 + b * b)
    unitario v = map (/ sqrt (sum (map (^ 2) v))) v

-- S^{-1/2} = Σ λ^{-1/2} v vᵀ, sumando sobre los pares propios de S
raizInversa2 :: Matriz Double -> Matriz Double
raizInversa2 s = foldr1 (zipWith (zipWith (+))) [ [ [ vi * vj / sqrt l | vj <- v ] | vi <- v ] | (l, v) <- propios2 s ]

sPol usa beta: \(S_{11} = \int\phi_1^2 = \int x^2(1 - x)^2\) es beta 2, y así. raizInversa2 aplica la definición de una función de una matriz simétrica: en la base de sus vectores propios, \(\mathbf S^{-1/2}\) es diagonal con elementos \(\lambda^{-1/2}\), y \(\sum_\lambda\lambda^{-1/2}\,\mathbf v\mathbf v^T\) la escribe en la base original.

Predice. ¿Cuánto vale la estimación con \(\phi_1\) sola, \(H_{11}/S_{11}\)? Si el valor de Ritz con las dos funciones es \(4.934875\) y el exacto es \(\frac{\pi^2}{2} = 4.9348022\), ¿cuántos valores propios de \((\mathbf H, \mathbf S)\) hay por debajo de \(4.934802\), de \(4.934874\), de \(4.934875\) y de \(52\)?

Lee.

  • Haskell escribe \(\frac ab\) como a % b. Son las matrices de la nota conceptual, y la estimación con una función es \(5\) exacto.
  • Los valores propios generalizados son \(4.934875\) y \(51.065\).
  • La cuenta en \(\mathbb{Q}\) da \(0, 0, 1, 2\): no hay ningún valor de Ritz por debajo de \(4.934874\), hay uno por debajo de \(4.934875\), y dos por debajo de \(52\). Es una prueba exacta, sin redondeo, de que \(4.934874 < E_1^{\text{Ritz}} < 4.934875\), y de que el valor de Ritz está por encima del exacto: la cota de MacDonald–Hylleraas–Undheim, certificada con fracciones.
  • \(\mathbf S^{-1/2}\) y \(\tilde{\mathbf H}\) son las de la nota conceptual: \(\tilde{\mathbf H}\) es simétrica, con traza \(7.553 + 48.447 = 56.0\), la suma de los dos valores propios.

Lo que la proyección no preserva

Añade a U5T3.hs:

-- el operador posición en los primeros n estados del oscilador: ⟨k|x|k+1⟩ = √((k+1)/2)
posicionX :: Int -> Matriz Double
posicionX n = [ [ elemento i j | j <- [0 .. n - 1] ] | i <- [0 .. n - 1] ]
  where
    elemento i j
      | j == i + 1 = sqrt (fromIntegral j / 2)
      | i == j + 1 = sqrt (fromIntegral i / 2)
      | otherwise  = 0

-- el bloque n×n de arriba a la izquierda
recortar :: Int -> Matriz a -> Matriz a
recortar n = map (take n) . take n

Predice. \((X_3)^2\) y la proyección de \(\hat x^2\) sobre los tres primeros estados, que se obtiene recortando \((X_5)^2\), ¿en qué elementos difieren?

Ejecuta.

ghci> matMul (posicionX 3) (posicionX 3)
[[0.5000000000000001,0.0,0.7071067811865476],[0.0,1.5,0.0],[0.7071067811865476,0.0,1.0]]

ghci> recortar 3 (matMul (posicionX 5) (posicionX 5))
[[0.5000000000000001,0.0,0.7071067811865476],[0.0,1.5,0.0],[0.7071067811865476,0.0,2.5]]

Lee. Coinciden en todo salvo el último elemento de la diagonal: \(1\) frente a \(2.5\), es decir, \(\frac12\cdot2\) frente a \(\frac12\cdot5\), como en la nota conceptual. El camino \(|2\rangle \to |3\rangle \to |2\rangle\) pasa por un estado que \(X_3\) no tiene. Recortar una matriz más grande sí da la proyección correcta, porque \(\hat x^2\) solo conecta estados que difieren en 2.

Tu turno. Repite la comparación con \(\hat x^4\): \((X_3)^4\) frente a recortar 3 de \((X_7)^4\). ¿Cuántos elementos difieren ahora? ¿Por qué hace falta recortar una matriz con al menos 2 estados más?

Idea. En el oscilador anarmónico, con la base anidada de los estados del oscilador armónico, los niveles bajan monótonamente y se entrelazan, como dice el teorema. Si en cambio se usa \((X_n)^4\), la matriz ya no es una proyección y la cota se rompe. Comparamos también diferencias finitas y Galerkin con sombreros, que encierran al valor exacto por lados opuestos, y medimos exactamente el condicionamiento de la base de polinomios.

Recuerda: con subespacios anidados, \(E_k^{(n)} \geq E_k^{(n+1)} \geq E_k\), y cada valor viejo queda entre dos nuevos (entrelazamiento de Cauchy).

Añade a U5T3.hs:

potencia :: Int -> Matriz Double -> Matriz Double
potencia k m = foldr1 matMul (replicate k m)

-- suma d_k a la diagonal
masDiagonal :: [Double] -> Matriz Double -> Matriz Double
masDiagonal ds m = [ [ if j == i then c + d else c | (j, c) <- zip [0 :: Int ..] f ] | (i, f, d) <- zip3 [0 ..] m ds ]

-- H = ½p² + ½x² + x⁴ en los primeros n estados: la parte armónica es diag(k + ½),
-- y x⁴ se recorta de una matriz con 4 estados más (elementos exactos)
anarmonico :: Int -> Matriz Double
anarmonico n = masDiagonal [ fromIntegral k + 0.5 | k <- [0 .. n - 1] ] (recortar n (potencia 4 (posicionX (n + 4))))

-- la versión ingenua: (X_n)⁴, que no es la proyección de x⁴
anarmonicoIngenuo :: Int -> Matriz Double
anarmonicoIngenuo n = masDiagonal [ fromIntegral k + 0.5 | k <- [0 .. n - 1] ] (potencia 4 (posicionX n))

-- Galerkin con sombreros en el pozo: H = K/(2h), S = (h/6)·tridiag(1, 4, 1)
sombreros :: Int -> (Matriz Double, Matriz Double)
sombreros n = (map (map (/ (2 * h))) (tridiag 2 (-1) n), map (map (* (h / 6))) (tridiag 4 1 n))
  where
    h = 1 / fromIntegral (n + 1)

-- κ₂(S) de la base x^k(1−x)^k, k = 1..m, con los valores propios extremos calculados en ℚ
traslapePol :: Int -> Matriz Rational
traslapePol m = [ [ beta (fromIntegral (i + j)) | j <- [1 .. m] ] | i <- [1 .. m] ]

kappaExacto :: Int -> Double
kappaExacto m = fromRational (lmax / lmin)
  where
    s    = traslapePol m
    cota = fromIntegral m * sum (map abs (head s))
    lmin = valorPropio 1 s (identidad m) (0, cota) 120
    lmax = valorPropio m s (identidad m) (0, cota) 60

En kappaExacto, la bisección corre sobre Rational: cada punto medio es una fracción exacta y cada cuenta de pivotes es exacta. Con 120 pasos, el menor valor propio queda determinado con precisión absoluta \(\text{cota}\times2^{-120}\), suficiente aunque valga \(10^{-19}\).

Predice. En la tabla del anarmónico, ¿puede subir algún nivel al pasar de \(n\) a \(n + 1\)? Con la versión ingenua y \(n = 5\), ¿quedará \(E_1\) por encima del valor convergido \(2.7379\)?
