La función de onda como lista de complejos. El estado es la lista de los valores de \(\psi\) en una malla uniforme. Retomamos los números complejos de /u3/t2, pero ahora polimórficos: Cx a tiene partes de tipo a, de modo que Cx Double sirve para la evolución y Cx Racional para comprobar exactamente, al final, que Crank-Nicolson es unitario. Cada integrador es una función de onda a onda, y la evolución es su iteración, como en la Unidad 3.

module U5T5

import Exacto
import Data.List
import Data.Maybe

%default total

-- números complejos a + b i con partes en cualquier tipo numérico
record Cx a where
  constructor MkCx
  re : a
  im : a

Num a => Neg a => Num (Cx a) where
  MkCx a b + MkCx c d = MkCx (a + c) (b + d)
  MkCx a b * MkCx c d = MkCx (a * c - b * d) (a * d + b * c)
  fromInteger n = MkCx (fromInteger n) 0

Num a => Neg a => Neg (Cx a) where
  negate (MkCx a b) = MkCx (negate a) (negate b)
  MkCx a b - MkCx c d = MkCx (a - c) (b - d)

Fractional a => Neg a => Fractional (Cx a) where
  MkCx a b / MkCx c d = let m = c * c + d * d in MkCx ((a * c + b * d) / m) ((b * c - a * d) / m)

Eq a => Eq (Cx a) where
  MkCx a b == MkCx c d = a == c && b == d

Show a => Show (Cx a) where
  show (MkCx a b) = "(" ++ show a ++ " + " ++ show b ++ "i)"

C : Type
C = Cx Double

conj : Neg a => Cx a -> Cx a
conj (MkCx a b) = MkCx a (negate b)

real : Double -> C
real x = MkCx x 0

-- la unidad imaginaria, y e^{iθ}
iU : C
iU = MkCx 0 1

cis : Double -> C
cis t = MkCx (cos t) (sin t)

-- |a + b i|, escalado para no elevar al cuadrado números enormes o diminutos (ver /u3/t2)
modulo : C -> Double
modulo (MkCx a b) =
  let m = max (abs a) (abs b)
  in if m == 0 then 0 else m * sqrt ((a / m) * (a / m) + (b / m) * (b / m))

Onda : Type
Onda = List C

-- una malla uniforme: número de puntos, primer punto y paso
record Malla where
  constructor MkMalla
  puntos : Nat
  xMin   : Double
  dx     : Double

xs : Malla -> List Double
xs m = [ xMin m + dx m * cast j | j <- [0 .. puntos m `minus` 1] ]

-- ‖ψ‖ = √(Σ |ψ_j|² Δx), y ⟨x⟩
norma : Malla -> Onda -> Double
norma m psi = sqrt (dx m * sum [ modulo z * modulo z | z <- psi ])

posicionMedia : Malla -> Onda -> Double
posicionMedia m psi = sum (zipWith (\x, z => x * modulo z * modulo z) (xs m) psi) / sum [ modulo z * modulo z | z <- psi ]

-- a + k·b, componente a componente; y aplicar un paso n veces
mas : Onda -> C -> Onda -> Onda
mas a k b = zipWith (\x, y => x + k * y) a b

evolucionar : Nat -> (Onda -> Onda) -> Onda -> Onda
evolucionar Z     _    psi = psi
evolucionar (S n) paso psi = evolucionar n paso (paso psi)

Las implementaciones de Num (Cx a) llevan restricciones: Cx a es un número si a lo es. Por eso la misma suma y el mismo producto funcionan con partes Double y con partes Racional. modulo se calcula escalado, como en /u3/t2, para que el módulo de un número de \(10^{160}\) no se desborde al elevarlo al cuadrado.

  • El peligro de los esquemas explícitos: Euler diverge; RK4 disipa y exige pasos diminutos
  • Crank-Nicolson: la aproximación de Cayley como mapa unitario
  • Split-operator: factorizar la exponencial del hamiltoniano
  • Conexión con el paradigma funcional y la verificación formal

Idea. Obtenemos la función de estabilidad \(R\) de Euler y de RK4 ejecutándolos una vez sobre un estado propio, como en /u3/t4. Después los aplicamos al estado coherente del oscilador en una malla de 256 puntos, donde la mayor energía de la matriz es \(E_{\max} \approx 370\).

Recuerda: sobre un estado de energía \(E\), un paso multiplica por \(R(-iEh)\); la evolución exacta, por \(e^{-iEh}\), de módulo 1.

-- H ψ con diferencias finitas (ver /u5/t3), con ψ = 0 fuera de la malla
hDF : Malla -> (Double -> Double) -> Onda -> Onda
hDF m v psi =
  let d2 = dx m * dx m
  in zipWith3 (\(izq, c, der), x, _ => real (-0.5 / d2) * (izq - 2 * c + der) + real (v x) * c)
              (zip3 (0 :: psi) psi (drop 1 psi ++ [0])) (xs m) psi

-- un integrador de ψ' = −i H ψ recibe H como función, el paso y la onda
Integrador : Type
Integrador = (Onda -> Onda) -> Double -> Onda -> Onda

euler : Integrador
euler op h psi = mas psi (MkCx 0 (-h)) (op psi)

rk4 : Integrador
rk4 op h psi =
  let f : Onda -> Onda
      f p = map (* MkCx 0 (-1)) (op p)            -- el campo: ψ ↦ −i H ψ
      k1 = f psi
      k2 = f (mas psi (real (h / 2)) k1)
      k3 = f (mas psi (real (h / 2)) k2)
      k4 = f (mas psi (real h) k3)
  in mas (mas (mas (mas psi (real (h / 6)) k1) (real (h / 3)) k2) (real (h / 3)) k3) (real (h / 6)) k4

-- R(−iy): un paso con h = 1 sobre un "estado" de una componente con H = y
factorR : Integrador -> Double -> C
factorR metodo y = fromMaybe 0 (head' (metodo (map (* real y)) 1 [1]))

-- el experimento de la nota conceptual: oscilador en [−10, 10) con 256 puntos
malla256 : Malla
malla256 = MkMalla 256 (-10) (20 / 256)

oscilador : Double -> Double
oscilador x = x * x / 2

-- el estado coherente: la gaussiana del estado fundamental, desplazada a x = 3
coherente : Malla -> Onda
coherente m = [ real (pow pi (-0.25) * exp (-(x - 3) * (x - 3) / 2)) | x <- xs m ]

psi0 : Onda
psi0 = coherente malla256

hOsc : Onda -> Onda
hOsc = hDF malla256 oscilador

periodo : Double
periodo = 2 * pi

-- (‖ψ‖ − 1, ⟨x⟩) al final
resumen : Malla -> Onda -> (Double, Double)
resumen m psi = (norma m psi - 1, posicionMedia m psi)

hDF recorre la onda con sus vecinos izquierdo y derecho (con ceros en los bordes) y aplica \(-\frac12\frac{\psi_{j-1} - 2\psi_j + \psi_{j+1}}{\Delta x^2} + V(x_j)\psi_j\): es la matriz de /u5/t3, sin construirla nunca. Los integradores no saben que el estado es una función de onda: reciben op, la función \(\psi \mapsto H\psi\). factorR los aplica a un estado de una sola componente, donde \(H\) es el número \(y\).

Idea. Un paso de Crank-Nicolson es \(\psi \mapsto A^{-1}(B\psi)\), con \(A = I + \frac{ih}{2}H\) tridiagonal. Escribimos el algoritmo de Thomas como evaluación parcial: factoriza \(A\) una vez y devuelve la función que resuelve, como resolverCon en /u4/t1. Medimos norma, centro, orden y energía en el estado coherente, y el comportamiento sobre un modo rápido en difusión y en Schrödinger.

Recuerda: \(\left(I + \frac{ih}{2}H\right)\psi^{n+1} = \left(I - \frac{ih}{2}H\right)\psi^n\), y la transformada de Cayley de una \(H\) hermítica es unitaria para cualquier \(h\).

Añade a U5T5.idr:

-- Thomas: LU sin pivoteo de una tridiagonal con diagonal `as` y elementos b fuera de ella;
-- factoriza una vez y devuelve la función que resuelve A x = r
thomas : List C -> C -> (Onda -> Onda)
thomas as b =
  let us = reverse (foldl (\acc, a => case acc of
                                        []          => [a]
                                        (u :: _)    => (a - b * b / u) :: acc) [] as)   -- pivotes
      ls = map (b /) (take (length us `minus` 1) us)                                    -- multiplicadores
  in \rs => let ys = reverse (foldl (\acc, (r, l) => case acc of
                                                       []       => [r]
                                                       (y :: _) => (r - l * y) :: acc)
                                    (take 1 rs) (zip (drop 1 rs) ls))                    -- L y = r
            in foldr (\(y, u), acc => case acc of
                                       []        => [y / u]
                                       (x1 :: _) => ((y - b * x1) / u) :: acc) [] (zip ys us)   -- U x = y

-- un paso de Crank-Nicolson: B ψ con B = I − (ih/2) H, y luego resolver A ψ' = B ψ
crankNicolson : Malla -> (Double -> Double) -> Double -> (Onda -> Onda)
crankNicolson m v h =
  let d2        = dx m * dx m
      resolverA = thomas [ 1 + MkCx 0 (h / 2) * real (1 / d2 + v x) | x <- xs m ] (MkCx 0 (-h / (4 * d2)))
  in \psi => resolverA (mas psi (MkCx 0 (-h / 2)) (hDF m v psi))

-- ‖a − b‖
distancia : Malla -> Onda -> Onda -> Double
distancia m a b = norma m (zipWith (-) a b)

-- ⟨H⟩ = Re⟨ψ|Hψ⟩ / ⟨ψ|ψ⟩, con el H de diferencias finitas
energiaDF : Malla -> (Double -> Double) -> Onda -> Double
energiaDF m v psi = re (sum (zipWith (\a, b => conj a * b) psi (hDF m v psi))) / sum [ modulo z * modulo z | z <- psi ]

thomas hace las tres fases de la eliminación de /u4/t1 para una tridiagonal: los pivotes us con un foldl (cada uno depende del anterior; la lista se arma al revés y se invierte), la sustitución hacia adelante con otro foldl, y la sustitución hacia atrás con un foldr, que recorre la lista de derecha a izquierda. Cada fase es \(O(n)\). En crankNicolson, resolverA se calcula una vez al construir el paso; cada paso solo aplica \(B\) y resuelve.

Predice. Con \(h = \frac{2\pi}{128} = 0.049\) y \(\frac{2\pi}{256} = 0.025\), ¿cuánto se apartará la norma de 1? ¿Llegará el paquete a \(\langle x\rangle = 3\)? ¿Con qué orden converge al dividir \(h\), comparando con la evolución exacta de la matriz (que aproximamos con 8192 pasos)?

Lee.

  • La norma se aparta de 1 en \(10^{-14}\): precisión de máquina, tras 128 o 256 pasos con un \(h\) entre 6 y 13 veces mayor que el máximo de RK4. Pero \(\langle x\rangle = 2.949\) y \(2.993\): el paquete se retrasa, por el error de fase.

Idea. Escribimos la FFT como una recursión de pocas líneas, y con ella el paso de Strang: \(e^{-iVh/2}\) en posiciones, \(e^{-ik^2h/2}\) en momentos, y otra vez \(e^{-iVh/2}\). Medimos su orden y su energía, el error de splitting en el caso de \(2\times2\), la precisión espectral, la periodicidad, y el error silencioso del orden de las frecuencias.

Recuerda: la FFT entrega los coeficientes en el orden \(0, 1, \ldots, \frac n2 - 1, -\frac n2, \ldots, -1\), y la DFT de \(\psi\) se separa en las DFT de los índices pares e impares.

Añade a U5T5.idr:

-- separa los elementos de índice par y de índice impar
separar : List a -> (List a, List a)
separar (a :: b :: r) = let (p, q) = separar r in (a :: p, b :: q)
separar r             = (r, [])

-- la transformada rápida de Fourier (n potencia de 2), sin normalizar: ψ̂_m = Σ ψ_j e^{−2πi jm/n}
fft : List C -> List C
fft zs = ir (length zs) zs
  where
    ir : Nat -> List C -> List C
    ir _     [z] = [z]
    ir Z     ws  = ws
    ir (S k) ws  =
      let n  = length ws
          (pares, impares) = separar ws
          es = ir k pares
          ts = zipWith (*) [ cis (-2 * pi * cast j / cast n) | j <- [0 .. n] ] (ir k impares)
      in zipWith (+) es ts ++ zipWith (-) es ts

-- la inversa, con el factor 1/n: conjugar, transformar, conjugar
ifft : List C -> List C
ifft zs = map (\z => conj z / real (cast (length zs))) (fft (map conj zs))

-- los números de onda en el orden de la FFT
numerosDeOnda : Malla -> List Double
numerosDeOnda m =
  let n = puntos m
      mitad = cast {to = Nat} (cast {to = Integer} n `div` 2)
  in [ 2 * pi * k / (cast n * dx m) | k <- map cast [0 .. mitad `minus` 1] ++ map (\j => cast j - cast mitad) [0 .. mitad `minus` 1] ]

-- un paso de Strang: e^{−iVh/2}, luego e^{−ik²h/2} en momentos, luego e^{−iVh/2}
splitOperator : Malla -> (Double -> Double) -> List Double -> Double -> (Onda -> Onda)
splitOperator m v ks h =
  let eV = [ cis (-h / 2 * v x) | x <- xs m ]
      eT = [ cis (-h / 2 * k * k) | k <- ks ]
  in \psi => zipWith (*) eV (ifft (zipWith (*) eT (fft (zipWith (*) eV psi))))

ks256 : List Double
ks256 = numerosDeOnda malla256

-- ⟨H⟩ con la energía cinética calculada en momentos
energiaEspectral : Malla -> (Double -> Double) -> List Double -> Onda -> Double
energiaEspectral m v ks psi =
  let pk = fft psi
      cin = sum (zipWith (\k, z => k * k / 2 * modulo z * modulo z) ks pk) / sum [ modulo z * modulo z | z <- pk ]
      pot = sum (zipWith (\x, z => v x * modulo z * modulo z) (xs m) psi) / sum [ modulo z * modulo z | z <- psi ]
  in cin + pot

fft es la recursión del repaso de la nota conceptual: separa pares e impares, transforma cada mitad, y las combina con los factores \(e^{-2\pi ij/n}\). Idris no ve que las mitades son más cortas que la lista, así que ir lleva como combustible la longitud. El paso de Strang es una composición de cinco funciones; como eV y eT se calculan al construir el paso, cada paso solo multiplica y transforma.

Predice. Tras un periodo, el estado coherente exacto es \(-\psi_0\). ¿Con qué orden converge split-operator a él? ¿Conservará la energía exactamente, como Crank-Nicolson?

El error de splitting, en un caso de 2×2

Añade a U5T5.idr:

-- matrices complejas de 2×2 como (a, b, c, d) = [[a, b], [c, d]]
M2 : Type
M2 = (C, C, C, C)

mul2 : M2 -> M2 -> M2
mul2 (a, b, c, d) (e, f, g, k) = (a * e + b * g, a * f + b * k, c * e + d * g, c * f + d * k)

lineal : C -> M2 -> C -> M2 -> M2                   -- α A + β B
lineal al (a, b, c, d) be (e, f, g, k) = (al * a + be * e, al * b + be * f, al * c + be * g, al * d + be * k)

sigmaX, sigmaZ, id2 : M2
sigmaX = (0, 1, 1, 0)
sigmaZ = (1, 0, 0, -1)
id2    = (1, 0, 0, 1)

-- e^{−ihσ} = cos h · I − i sin h · σ, porque σ² = I
expPauli : Double -> M2 -> M2
expPauli h s = lineal (real (cos h)) id2 (MkCx 0 (-sin h)) s

-- e^{−ih(σx + σz)}: como (σx + σz)² = 2I, es la misma fórmula con √2 h
exactaTV : Double -> M2
exactaTV h = let r = sqrt 2 * h in lineal (real (cos r)) id2 (MkCx 0 (-sin r / sqrt 2)) (lineal 1 sigmaX 1 sigmaZ)

-- norma 2 (ver /u4/t1): raíz del mayor valor propio de A†A
norma2 : M2 -> Double
norma2 (a, b, c, d) =
  let (x, y, _, w) = mul2 (conj a, conj c, conj b, conj d) (a, b, c, d)
      p = re (x + w) / 2
      q = re (x - w) / 2
  in sqrt (p + sqrt (q * q + modulo y * modulo y))

-- errores del producto simple y de Strang frente a la exponencial exacta
erroresSplitting : Double -> (Double, Double)
erroresSplitting h =
  let ex     = exactaTV h
      simple = mul2 (expPauli h sigmaX) (expPauli h sigmaZ)
      strang = mul2 (expPauli (h / 2) sigmaZ) (mul2 (expPauli h sigmaX) (expPauli (h / 2) sigmaZ))
  in (norma2 (lineal 1 simple (-1) ex), norma2 (lineal 1 strang (-1) ex))

Una matriz de \(2\times2\) es aquí una cuádrupla (a, b, c, d); lineal α A β B es \(\alpha A + \beta B\), y con ella se escriben todas las combinaciones. En norma2, (conj a, conj c, conj b, conj d) es la adjunta \(A^\dagger\).

Predice. Al dividir \(h\) entre 2, ¿por cuánto se divide el error del producto simple? ¿Y el de Strang?

Ejecuta.

U5T5> :exec printLn (map erroresSplitting [0.2, 0.1, 0.05])
[(0.03964588352895138, 0.0029612080728111745), (0.009977800297338624, 3.720448956560831e-4), (0.0024986114631116996, 4.6564954545013226e-5)]

Lee. Es la tabla de la nota conceptual: el producto simple da \(4.0\times10^{-2},\ 1.0\times10^{-2},\ 2.5\times10^{-3}\) (se divide entre 4: error local \(O(h^2)\), el conmutador \(\frac{h^2}{2}[T, V]\)), y Strang \(3.0\times10^{-3},\ 3.7\times10^{-4},\ 4.7\times10^{-5}\) (se divide entre 8: \(O(h^3)\)).

Precisión espectral, periodicidad y un error silencioso

Añade a U5T5.idr:

-- error espacial con n puntos en [−10, 10): Fourier (2048 pasos) y diferencias finitas (CN con 4096 pasos)
errorEspacialFourier : Nat -> Double
errorEspacialFourier n =
  let m  = MkMalla n (-10) (20 / cast n)
      p0 = coherente m
  in distancia m (evolucionar 2048 (splitOperator m oscilador (numerosDeOnda m) (periodo / 2048)) p0) (map negate p0)

errorEspacialDF : Nat -> Double
errorEspacialDF n =
  let m  = MkMalla n (-10) (20 / cast n)
      p0 = coherente m
  in distancia m (evolucionar 4096 (crankNicolson m oscilador (periodo / 4096)) p0) (map negate p0)

-- un paquete libre en [−20, 20) con 512 puntos: ψ₀ ∝ e^{−(x+10)²/8} e^{5ix}
malla512 : Malla
malla512 = MkMalla 512 (-20) (40 / 512)

paqueteLibre : Onda
paqueteLibre =
  let p = [ real (exp (-(x + 10) * (x + 10) / 8)) * cis (5 * x) | x <- xs malla512 ]
  in map (\z => z / real (norma malla512 p)) p

-- con V = 0, la evolución hasta t es exacta en momentos: un solo factor e^{−ik²t/2}
libre : Double -> Onda
libre t = ifft (zipWith (\k, z => cis (-k * k * t / 2) * z) (numerosDeOnda malla512) (fft paqueteLibre))

Predice. ¿Cómo baja el error espacial con \(n\) en cada base? ¿Dónde estará el paquete libre en \(t = 6\) y \(t = 8\), si su centro debería estar en \(-10 + 5t\)? Si los \(k\) se ordenan de menor a mayor (con sort), ¿seguirá conservándose la norma?

Lee.

  • En Fourier, \(0.13\) con 32 puntos y \(1.3\times10^{-5}\) con 64 y con 128: una vez resuelto el paquete, el error espacial desaparece y queda el temporal. En diferencias finitas, \(0.37,\ 0.093,\ 0.023\): se divide entre 4 por duplicación, y con 512 puntos sigue siendo del 2 %. Es la tabla de la nota conceptual.
  • El paquete libre está en \(0\) y en \(10\) en \(t = 2\) y \(4\). En \(t = 6\), \(\langle x\rangle = -0.24\): el paquete está partido entre los dos bordes. En \(t = 8\), \(-9.97\): reapareció por la izquierda. La norma es 1 en todo momento.

Tu turno. Añade al paquete libre un potencial absorbente cerca de los bordes, \(V(x) = -0.5\,i\,(|x| - 15)^2\) para \(|x| > 15\). Como el potencial es complejo, generaliza splitOperator para que eV sea \(e^{-iVh/2} = e^{-i\,\mathrm{Re}(V)h/2}\,e^{\mathrm{Im}(V)h/2}\). ¿Qué pasa ahora con la norma en \(t = 8\), y con \(\langle x\rangle\)?

Idea. La unitariedad de Crank-Nicolson es una igualdad, \(U^\dagger U = I\), y con \(H\) y \(h\) racionales se puede comprobar exactamente: las entradas de \(U\) son números complejos con partes racionales, es decir, valores de tipo Cx Racional. Las mismas implementaciones de Num y Fractional de Cx a sirven, y la igualdad se comprueba con ==.

Recuerda: \(U = (I + iA)^{-1}(I - iA)\) con \(A = \frac h2H\); en el ejemplo de la nota conceptual, con \(H = \sigma_x\) y \(h = 1\), \(U = \frac35I - \frac45iH\).

Añade a U5T5.idr:

-- eliminación gaussiana sin pivoteo (ver /u4/t1), en cualquier tipo fraccionario; combustible: las filas
resolverSistema : Fractional a => Neg a => List (List a) -> List a -> List a
resolverSistema m bs = ir (length m) m bs
  where
    ir : Nat -> List (List a) -> List a -> List a
    ir (S k) ((p :: fila) :: resto) (b :: bs') =
      let reducir : (List a, a) -> (List a, a)
          reducir (c :: f, bi) = (zipWith (\u, w => u - c / p * w) f fila, bi - c / p * b)
          reducir ([], bi)     = ([], bi)
          reducidas = map reducir (zip resto bs')
          xs'       = ir k (map fst reducidas) (map snd reducidas)
      in (b - sum (zipWith (*) fila xs')) / p :: xs'
    ir _ _ _ = []

identidadQ : Nat -> List (List (Cx Racional))
identidadQ n = [ [ (if i == j then 1 else 0) | j <- [1 .. n] ] | i <- [1 .. n] ]

-- U = (I + i h/2 H)⁻¹ (I − i h/2 H), resolviendo columna por columna, en Cx Racional
cayleyExacta : List (List Racional) -> Racional -> List (List (Cx Racional))
cayleyExacta hm h =
  let ident = identidadQ (length hm)
      a = zipWith (zipWith (\d, x => d + MkCx 0 (h / 2 * x))) ident hm
      b = zipWith (zipWith (\d, x => d - MkCx 0 (h / 2 * x))) ident hm
  in transpose [ resolverSistema a columna | columna <- transpose b ]

-- U†U: el producto interno de cada par de columnas
productoAdjunto : List (List (Cx Racional)) -> List (List (Cx Racional))
productoAdjunto u = let cols = transpose u in [ [ sum (zipWith (\x, y => conj x * y) ci cj) | cj <- cols ] | ci <- cols ]

resolverSistema es la eliminación sin pivoteo de /u4/t1, con combustible para ser total, y no sabe de qué tipo son los números: con Cx Racional da resultados exactos. Funciona sin pivoteo porque \(I + iA\) es diagonalmente dominante. La implementación Show (Cx a) imprime las partes con el Show de Racional, como fracciones.

Predice. ¿Saldrá \(U = \frac35I - \frac45i\,\sigma_x\) exactamente? Para la matriz \(K\) de la Unidad 4 con \(h = \frac12\), ¿será \(U^\dagger U\) exactamente la identidad?

  • \(U = \begin{pmatrix}\frac35 & -\frac45i\\ -\frac45i & \frac35\end{pmatrix}\): la rotación de la nota conceptual, en fracciones, y \(U^\dagger U = I\) sin redondeo.
  • Para \(K\) con \(h = \frac12\), \(U\) tiene entradas como \(\frac{327}{565} - \frac{406}{565}i\), y la comparación con la identidad da True. La proposición “Crank-Nicolson conserva la norma” es una igualdad que, en aritmética exacta, el programa verifica, no aproxima. En Double, la misma comprobación fallaría en la última cifra.
